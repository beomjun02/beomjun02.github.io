Papers

  • 🆕 World Action Models: A Survey
    arXiv cs.RO · 2026-06-24 · world modelComprehensive survey clarifying the boundary between world models, video generation models, VLAs, and World Action Models (WAMs). Organizes the field through what each method generates (rendered futures, latent futures, video-free reasoning) and how action is coupled. A useful map of where the WAM field stands now.
  • 🆕 SafeDojo: Safe RL for VLA via Interactive World Model
    arXiv cs.RO · 2026-06-24 · VLA · world modelFirst model-based safe RL framework for VLA policies. Uses an interactive video world model to imagine action consequences, then decouples task reward from safety cost through a Lagrangian-based constrained GRPO objective. Achieves best safe-success rate on SafeLIBERO and validates on real Franka deployment across five tasks.
  • 🆕 Vesta: A Generalist Embodied Reasoning Model
    arXiv cs.RO · 2026-06-24 · robot foundation modelUnified foundation model consolidating localization, spatial reasoning, navigation, and long-horizon planning into a single model — avoiding the cascading errors of multi-model stacks. Beats individual SOTA baselines by >20% on average and improves real-world task success by >35% on tasks requiring memory and reasoning.
  • 🆕 MV-WAM: Manifold-Aware World Action Model with Value Augmentation
    arXiv cs.RO · 2026-06-24 · world-action modelEnd-to-end framework jointly modeling visual prediction, action generation, and value estimation. Addresses the structural mismatch between visual and action manifolds that causes WAMs to degrade out-of-distribution. Achieves 55.7% mean success on RoboTwin random scenarios (29.3% over best baseline) and 77.5% on real dual-arm tasks.
  • 🆕 BayesFP: Posterior Estimation for Flow-Based Policies via Feynman-Kac Sampling
    arXiv cs.RO · 2026-06-24 · VLA · sim-to-real RLInference-time, retraining-free sampler that adds safety constraints to pretrained flow-matching policies. Validated on Diffusion Policy, GR00T-N1.6, and π0.5 checkpoints — demonstrating zero-shot task improvements on real and simulated manipulation including planning around non-convex obstacles introduced at test time.
  • 🆕 MotionPyramid: Hierarchical Motion Representation for Humanoid Control
    arXiv cs.CV · 2026-06-24Learns a recursive hierarchy of motion representations from data: coarse latents decode into temporally extended motion programs, fine latents provide frame-level motor commands. Residual Interfaces let a downstream RL policy maintain commands at multiple temporal scales simultaneously — structured abstraction without sacrificing controllability.
  • 🆕 Foresight: Failure Detection for Long-Horizon Robotic Manipulation
    HF papers · 2026-06-24 · world modelMonitors manipulation trajectories using latent representations from an action-conditioned world model. Trained with only final task-level labels (no dense temporal annotations), detects failure onset in long-horizon tasks where the moment of failure is ambiguous — a practical safety layer for deployed VLA systems.
