  • 🆕 CLIFT: Turning Gemini Robotics On-Device into Humanoid Specialists via Non-Invasive Closed-Loop Iterative Fine-Tuning
    arXiv cs.RO · 2026-08-04 · VLAProposes a closed-loop iterative fine-tuning method for adapting closed-weight robot foundation models (like Gemini Robotics) via managed SFT APIs.   • 🆕 WCM: A World Critic Model for Vision-Language-Action Reinforcement Learning
    arXiv cs.RO · 2026-08-04 · VLATackles the observation-history bottleneck in VLA critic design by introducing a world-model-based value estimator. Standard critics operate on single-frame observations, which fundamentally mismatches the partially observable nature of robot control; WCM uses video prediction as an auxiliary objective to build temporally grounded value estimates for RL post-training.
  • 🆕 ActFovea: Runtime Safeguarding for VLA Policies via Spatiotemporal Visual-Action Consistency
    arXiv cs.RO · 2026-08-04 · VLAPlug-and-play framework that detects and mitigates VLA runtime failures without retraining. Uses robot kinematics and recent actions to construct action-conditioned foveated visual regions, checking spatiotemporal consistency between what the policy sees and what it commands — a practical safety layer for deploying VLAs in unstructured environments.
  • 🆕 FibVLA: An Efficient Temporal Vision-Language-Action Model with Fibonacci Sampling
    arXiv cs.RO · 2026-08-04 · VLAAddresses the efficiency-versus-temporal-reasoning tradeoff in VLAs by sampling observation history at Fibonacci-spaced intervals rather than encoding the full context. Maintains temporal awareness for action inference while significantly reducing the computational cost of processing long observation histories.
  • UniCross: Unified Cross-Skill Dexterous Manipulation Synthesis
    arXiv cs.RO · 2026-08-02Unifies four canonical dexterous manipulation skills — grasping, relocation, in-hand rotation, and in-hand translation — into a single formulation sharing state/action spaces. Enables a cross-skill policy that generalizes to unseen objects, handles disturbances, and chains skills into long-horizon manipulation sequences across hand morphologies.
  • RedFlow: Redirect Failure into Action-Level Corrections for Flow-matching VLA Policy
    arXiv cs.RO · 2026-08-01 · VLAOffline RL framework that converts VLA failure trajectories into action-level corrective supervision. Context-aware matching finds successful alternatives for failed actions; an adaptive redirection objective jointly reinforces, suppresses, and redirects. Real-world success rate improves from 56.7% to 74.7%, matching on-policy methods (PPO, GRPO) with ~10× fewer samples.
