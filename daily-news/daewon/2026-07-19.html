  • 🆕 Smarter and Cheaper at Once: Byte-Exact KV-Cache Grafting Turns a Frozen Small Model into a Verified Decoding Accelerator
    arXiv cs.CL · 2026-07-18 · kv cache compression · sLMDeposits verified knowledge as a byte-exact KV-state artifact into a frozen small language model, then restores it by "graft" at inference — achieving bit-identical logits (SHA-256 verified, zero KL divergence) with no weight changes. Enables a small model to act as both a knowledge store and a verified-output accelerator, combining the benefits of KV caching with inference-time knowledge injection.
  • D-cut: Adaptive Verification Depth Pruning for Batched Speculative Decoding
    arXiv cs.CL · 2026-07-18 · speculative decodingAddresses the throughput collapse of speculative decoding under high batch concurrency, where long drafts waste compute on rejected tokens. D-cut adaptively prunes draft depth across the batch — selecting which tokens to verify jointly — so that speculative decoding remains beneficial even at production-level request loads rather than reverting to slower autoregressive fallback.
  • Polestar: Drift-Aware Cache Calibration and Token Commitment for Efficient Inference of Diffusion LLMs
    arXiv cs.CL · 2026-07-18 · efficient inferenceIdentifies "token representation drift" as the shared root cause behind two efficiency bottlenecks in diffusion LLMs: the inability to reuse KV caches under bidirectional attention and quality degradation from static confidence thresholds. Polestar uses drift as a unified signal for cache recalibration and adaptive token commitment — a training-free framework that improves inference speed without sacrificing generation quality.
  • PReM: Learning What to Preserve and When to Refresh for Context Compression
    arXiv cs.CL · 2026-07-18 · kv cache compressionIntroduces a Preserve-and-Refresh Memory framework for long-context inference that dynamically decides which KV entries to keep versus replace as generation proceeds, rather than making a single early compression decision. Unlike static KV-cache eviction, PReM adapts the compressed context to match the evidence needed by later reasoning steps, improving both memory efficiency and downstream accuracy.
  • Multi-Head Latent Control: A Unified Interface for LLM Agent Decision Making

  • SEED: Self-Evolving On-Policy Distillation for Agentic Reinforcement Learning

  • LongStraw: Long-Context RL Beyond 2M Tokens under a Fixed GPU Budget

  • ShortOPD: Recovering Pruned LLMs with Short-to-Long On-Policy Distillation
