  • 🆕 VarRate: Training-Free Variable-Rate KV Cache Compression for Long-Context LLMs
    arXiv cs.CL · 2026-07-21 · kv cache compressionAssigns each token a variable low-rank budget based on query salience instead of evicting tokens entirely. At a matched 20% memory budget on LongBench (16 tasks), VarRate stays within 0.8 points of uncompressed on both Llama-3.1-8B and Qwen2.5-7B — the strongest matched-memory compressor across both models, at roughly 1/8 the prefill overhead of KVzip.
  • 🆕 SpecVocab: Speculative Decoding with a Speculative Vocabulary
    arXiv cs.CL · 2026-07-21 · speculative decodingProposes per-step vocabulary subset selection for the draft model instead of using a permanently reduced vocabulary. Achieves higher acceptance length than EAGLE-3 and up to 8.1% throughput increase, solving the out-of-vocabulary problem that degrades existing reduced-vocab draft approaches.
  • 🆕 Looped Latent Attention: Cross-Loop KV Compression for Looped Transformers
    arXiv cs.LG · 2026-07-21 · kv cache compressionExploits the observation that KV vectors in weight-tied looped Transformers trace short low-rank trajectories across loops. Stores compact latents and reconstructs loop-specific KV on demand, achieving 21.3x cache compression on one H200 and increasing Ouro-1.4B batch capacity from 32 to 768 sequences at 4K context. Outperforms MLA, cross-layer sharing, KV quantization, and final-loop reuse at matched budgets.
  • 🆕 Loop the Loopies!
    arXiv cs.CL · 2026-07-21 · sLMLoopie is a looped MoE Transformer (20B total / 2B active, and 6B / 0.6B active) that substantially outperforms vanilla Transformer baselines trained with the same compute. Addresses the long-standing challenge that scaling params by N usually beats looping N times. Achieves gold-medal performance at IMO and IPhO without tools.
  • 🆕 GenDistill: Generation-Focused Distillation of Hybrid Sequence Models
    arXiv cs.CL · 2026-07-21 · efficient inferenceShows that log-likelihood evaluation systematically underestimates the teacher-student gap — a distilled 7B model within 0.2pp on log-likelihood scoring falls behind by 20.8pp when it must generate autoregressively. Best recipe distills into a Hybrid-KDA student retaining 86–90% teacher accuracy while reducing KV cache memory by up to 75% and improving time-to-first-token by 2–4x at 128K contexts.
  • 🆕 BIRD: Bootstrapped Iterative Self-Reasoning Distillation for Compressed Reasoning
    arXiv cs.CL · 2026-07-21 · efficient inferenceTwo-stage self-distillation that first warm-starts the model on concise traces via prompt-switch SFT, then applies on-policy reverse-KL distillation on cleaner prefixes. On Qwen3-8B, improves MATH-500 accuracy from 86.2% to 92.0% while cutting average response length from 3,099 to 1,115 tokens — a strong accuracy-efficiency tradeoff.
  • 🆕 CAPC: Cache-Aware Prompt Compression
    arXiv cs.LG · 2026-07-21 · token costCharacterizes Anthropic Sonnet 4.6's two-tier cache architecture and shows query-aware compression mechanically invalidates prefix caching on every call. CAPC pairs query-agnostic compression with tier-preserving ratio bounds, achieving 49% savings over cache-only, 64% over query-aware compression, and 90% over vanilla on LongBench-v2, with quality within 0.05 of uncompressed.
  • 🆕 PATR: Process-Scorer Guided Adaptive Tree Rollout for Multi-Turn Agent RL
    arXiv cs.CL · 2026-07-21 · agentReframes multi-turn agentic RL exploration as deciding where to branch in a trajectory tree. Uses process feedback to score partial trajectories, selectively branches from promising states, and stops degenerate paths. Improves by +5.0 points on SWE-Bench and +9.3 on FrozenLake, the first tree-rollout agent RL method evaluated on SWE-Bench.

    arXiv cs.RO · 2026-07-21 · reasoningIdentifies two failure modes in VLAs for unseen task combinations — trajectory overfitting and perceptual shortcut from wrist-view textures.
