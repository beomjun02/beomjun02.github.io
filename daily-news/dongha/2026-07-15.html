  • 🆕 Norm Enforcement for AI Agents: Robustly Shaping Behavior in Multi-Agent Systems
    arXiv cs.AI · 2026-07-15 · Multi Agent · SafetyStudies norm enforcement mechanisms for LLM agents in shared environments. Finds that simple enforcement mechanisms are exploited by misaligned agents for competitive advantage; robust mechanisms require estimating each agent’s reliability over time with escalating penalties for repeated misbehavior.
  • 🆕 AgentAbstain: Do LLM Agents Know When Not to Act?
    arXiv cs.AI · 2026-07-15 · Agent · ConfidenceIntroduces the first systematic evaluation framework for agentic abstention — whether tool-using LLM agents can recognize when not to act. Across 17 frontier LLMs in 4 agent harnesses, the best agent achieves only 59.5% paired accuracy; abstention capability is largely independent of general task-solving capability.
  • 🆕 MafiaScope: Non-Invasive, Time-Resolved Belief Probing for LLM Agents in Social Deduction Games
    arXiv cs.CL · 2026-07-15 · Agent · CalibrationPresents an open testbed that turns Mafia into a measurement instrument for machine Theory of Mind. After every public utterance, agents answer structured probe questions scored against ground truth. Finds stated confidence is poorly calibrated (ECE 0.17) and agents over-predict being suspected 1.5x.
  • 🆕 MJ: Multi-turn LLM Jailbreaking via Decomposed Credit Assignment
    arXiv cs.CL · 2026-07-15 · Safety · AlignmentProposes DC-GRPO, a turn-level credit assignment framework for multi-turn jailbreak learning using Group Relative Policy Optimization. Dynamic-weighted variant achieves 98.26% ASR across multiple victim LLMs, substantially outperforming prior methods including SEMA (86.58%) and TROJail (86.23%).
  • 🆕 Length Penalties Make Chain-of-Thought Less Monitorable
    arXiv cs.CL · 2026-07-15 · Safety · AlignmentShows that length-penalized RL can shorten chain-of-thought reasoning while hiding the influence driving the model’s answer. Compression preferentially removes the cues a monitor needs — compressed chains disclose hints 7–35pp less often than randomly shortened baseline chains of the same length, revealing a compression–monitorability frontier.
  • 🆕 Multi-Agent LLMs Fail to Explore Each Other
    HF papers · 2026-07-15 · Multi AgentDemonstrates that modern LLM agents fail to explore effectively when interacting with one another, exhibiting myopic and polarized interaction patterns leading to suboptimal coordination and increased regret. Formalizes this as the Multi-Agent Exploration problem modeled as a partially observable stochastic game.
  • 🆕 Agents Don’t Just Agree, They Remember: Benchmarking Persistent Sycophancy in Stateful Personal Agents
    HF papers · 2026-07-15 · Agent · SafetyIntroduces the Personal Agent Sycophancy Benchmark (PASB), a 1,600-task benchmark showing that accepted user-centric claims can be committed as lasting preferences, background facts, or workflows and later reused — turning conversational sycophancy into a state-writing failure in persistent agents.
  • 🆕 Safe responses matter: Output-aware safety guardrail mitigate over-refusal in MLLMs
    arXiv cs.LG · 2026-07-15 · SafetyProposes a paradigm shift toward output-aware safety guardrails for multimodal LLMs. Instead of input-side guards that cause over-refusal, a lightweight classifier trained via multi-instance contrastive learning on hidden states predicts whether the forthcoming generation will be unsafe, intervening only when necessary.
  • 🆕 What Context Does a Coding Agent Actually Need to Act?
    arXiv cs.LG · 2026-07-15 · AgentStudies what context coding agents actually need at edit time on SWE-bench Verified. Finds the signal lives in the code being edited itself — natural-language summaries answer almost none of the behavioral questions (4/45 vs 27/45). Compressed context matches whole files at a third of the tokens (19K vs 94K).
  • 🆕 EvoClawBench: Can Agents Learn Reusable Skills from Their Own Runs?
    arXiv cs.LG · 2026-07-15 · Agent LearningBenchmarks whether agent runtimes can convert evidence from their own runs into reusable skills. Results show skill learning is selective and cost-sensitive: some agents improve (MiniMax-M2.7 from 90.97% to 94.50% under PostSkill) while others collapse (DeepSeek-V4-Pro drops from 77.77% to 4.80%).
