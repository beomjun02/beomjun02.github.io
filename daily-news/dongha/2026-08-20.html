  • 🆕 Safety Alignment Illusion: The Cross-Lingual Safety Gap in LLMs
    arXiv cs.AI · 2026-08-20 · Safety · Alignment · LLMCurrent safety alignment training is heavily English-centric; this paper shows that safety filters fail for non-English languages, allowing models to bypass alignment in voice assistants and dialogue systems. The work highlights that cross-lingual transfer of safety behavior remains an unsolved problem with real deployment consequences.
  • 🆕 When Safety Overrides Vision: Exploring Dynamics between Vision Influence and Safety Alignment in Vision-Language Models
    arXiv cs.CV · 2026-08-20 · Safety · AlignmentAligned VLMs are designed to balance visual reasoning with safe generation, but this paper reveals that under safety-constrained instructions models frequently refuse to answer questions they can correctly answer otherwise. The finding suggests safety alignment may be overly aggressive, suppressing grounded visual capabilities.
  • 🆕 Different Facets of Verbalised Overconfidence: an Interpretability Study
    arXiv cs.CL · 2026-08-20 · ConfidenceStudies LLM overconfidence in Qwen3-4B using controlled reasoning scenarios that manipulate logical necessity and possibility. Examines three ways to express uncertainty — verbal epistemic markers, calibrated probabilities, and hedging — revealing that overconfidence manifests differently across modalities and is tied to distinct internal mechanisms.
  • 🆕 Competence, Not Accuracy: A Diagnostic for Reference-Free Judge Gates in Skill Optimization
    arXiv cs.AI · 2026-08-20 · CalibrationProposes a diagnostic framework for LLM-judge gates in text-space skill optimization. Existing gates rely on verifiable rewards; this work replaces the verifier with an LLM-judge gate and provides a calibration diagnostic to ensure the judge measures competence rather than accuracy, enabling skill optimization on tasks without automatic verifiers.
  • 🆕 Position: Multi-Agent Systems Should Prioritize Concurrency Control
    arXiv cs.AI · 2026-08-20 · Multi AgentArgues that many LLM-based multi-agent system failures are fundamentally concurrency control problems — agents concurrently read and write shared state, and long LLM inference windows amplify race conditions. Proposes that MAS frameworks should adopt database-style concurrency primitives to improve reliability as agent count scales.
  • 🆕 Co-RL: Unsupervised Reasoning Emerges from Diverse Cohort in Multi-agent RL
    HF papers · 2026-08-20 · Multi Agent · Agent LearningDemonstrates that unsupervised reasoning capabilities emerge when training with diverse agent cohorts in multi-agent RL, without requiring ground-truth supervision or verifiable rewards.   • 🆕 Looped Language Models Improve Compositional Tool Calling
    arXiv cs.AI · 2026-08-20 · Agent · LLMShows that looped language models — which reuse transformer layers iteratively — substantially improve compositional tool-calling performance where models must coordinate multiple API calls, maintain intermediate state, and preserve dependencies across tool interactions. Both native and retrofitted looped models outperform standard single-pass architectures.
  • 🆕 Persona-Guided LLM Agents for Task-Oriented Dialogue

  • 🆕 RTPO: Reverse-Turn Policy Optimization for Stabilizing Agentic RL Training
    arXiv cs.AI · 2026-08-20 · Agent LearningAddresses the instability of multi-turn RL training for agentic LLM workflows (tool use, iterative search).   • 🆕 Temporal Multi-Signal Fusion for Token-Level Hallucination Detection
    arXiv cs.CL · 2026-08-20 · Trustworthy · LLMTreats hallucination as a temporally extended span rather than independent per-token events. Fuses 33 temporal signals via sequence labeling, succeeding where single-signal detectors fail — specifically when the generating model is confidently wrong. A practical step toward reliable hallucination monitoring in deployed LLMs.
  • 🆕 SkillGate: Training In-Policy Skill Selection in Long-Horizon Agents
    HF papers · 2026-08-20 · AgentAgent frameworks package procedural knowledge as skills that agents read on demand, but deciding which skill to invoke mid-episode has no training signal. This work shows that naive outcome-rewarded RL fails at skill selection and proposes SkillGate, a method that trains in-policy skill selection for long-horizon tasks from skill libraries.
  • 🆕 Role-Conditioned Sub-Token Routing for Efficient Vision-Language-Action Policies
    arXiv cs.LG · 2026-08-20 · VLAVLA models process long multimodal token sequences, making inference expensive. Instead of aggressive token pruning (which discards entire representations), this work routes computation at the sub-token level conditioned on each token's role (vision, language, action), achieving significant efficiency gains without the fragility of token dropping.
