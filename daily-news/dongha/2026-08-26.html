  • 🆕 Spine-Branch Coordination for Multi-agent Computer Use
    arXiv cs.CL · 2026-08-26 · Multi Agent · AgentMulti-agent computer-use systems cannot merge VM states, yet prior work handles this ad-hoc. This framework decomposes tasks into a "spine" carrying main flow with continuous VM state and parallel "branch" tasks for information collection (VMs discarded after).   • 🆕 The Collaboration Tax: How Much LLM Multi-Agent Systems Pay to Coordinate
    arXiv cs.CL · 2026-08-26 · Multi Agent · LLMFormalizes the performance loss when two LLMs must coordinate rather than act alone, measured across 32 tasks and 11 models. The tax follows two no-exception axes: a consistent category ordering across every model and monotonic decrease with capability. The proximate cause is a four-stage conversational cascade of ungrounded claims and skipped verification.
