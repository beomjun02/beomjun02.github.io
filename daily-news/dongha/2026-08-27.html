  • 🆕 When "Must" Becomes "Maybe": Constraint Weakening in LLM Agent Workflows
    HF papers · 2026-08-27 · Agent · SafetyIdentifies a new failure mode where hard constraints (e.g. "must verify before executing") silently degrade into soft suggestions as they pass through summarization, planning, and handoff stages in multi-agent LLM pipelines. The paper formalizes constraint weakening, builds a benchmark to measure it, and shows current models lose up to 72% of action-constraining requirements across pipeline stages.
  • 🆕 More Rejective, Not More Discriminative: The Unit of Verification in Pre-Execution LLM Oversight
    arXiv cs.AI · 2026-08-27 · Safety · LLMStudies how many actions a single monitor call should review in AI-control settings where a fallible LLM vets planned actions before irreversible execution. Using controlled synthetic traces to isolate the variable, the work shows that reviewing actions one-at-a-time makes monitors more rejective (higher catch rate) but not more discriminative — a key distinction for calibrating trusted monitoring pipelines.
  • 🆕 StepGuard: Learning Step-Level Guardrails with Scalable Supervision and Safety-Utility Balancing
    HF papers · 2026-08-27 · Safety · AgentProposes a step-level guard model that can both audit completed agent trajectories and intercept dangerous tool calls before execution. Trains the guardrail using scalable synthetic supervision and a safety-utility objective that explicitly trades off blocking harmful actions against preserving agent usefulness, addressing the over-blocking problem that leads deployers to disable oversight entirely.
  • 🆕 SecOPD: Mitigating Adaptive Prompt Injections by On-Policy Distillation
    HF papers · 2026-08-27 · Safety · AgentAddresses the #1 OWASP threat to AI agents — prompt injection — by noting that existing defensive fine-tuning fails against adaptive attacks because training-time injections diverge from test-time attack distributions. SecOPD uses on-policy distillation where the model generates its own attack-conditioned rollouts for training, substantially reducing attack success rates where prior methods showed near-100% vulnerability.
  • 🆕 Knowing When to Ask for Help: Bayesian Self-Escalation in Hierarchical LLM Agents
    arXiv cs.LG · 2026-08-27 · Agent · ConfidenceIntroduces a third delegation regime for LLM agents: rather than routing before reasoning starts or verifying after it ends, an agent recognizes mid-reasoning that it is unlikely to succeed and transfers control to a stronger model. Formulates this as Bayesian optimal stopping over a learned competence posterior — an online estimate of eventual task success updated at each reasoning step.
  • 🆕 RecurSE: Bounded Recursive Self-Evaluation for LLM Rubric Judges
    arXiv cs.CL · 2026-08-27 · LLM · CalibrationEliminates external gold supervision from RL training rewards for LLM judges: the model's own evaluative capability generates the learning signal in a closed loop of bounded recursive self-improvement. Shows that with proper bounding, this recursive self-evaluation converges to judge quality competitive with distillation from stronger teachers — without requiring any external annotations.
  • 🆕 Who is the Agent to Blame? Localizing Faithfulness and Citation Mistakes in Agentic Deep Research
    arXiv cs.CL · 2026-08-27 · Agent · TrustworthyDeep-research systems produce long-form cited reports through multi-agent search and synthesis, but citation recall remains poor. This work localizes where faithfulness and citation errors enter the pipeline — identifying which specific agent in a multi-agent architecture is responsible for content corruption or citation loss, enabling targeted improvements rather than end-to-end retraining.
  • 🆕 From Causal Plausibility to Causal Reliability: Evaluating LLMs as Calibrated Direct Causal-Edge Classifiers
    arXiv cs.LG · 2026-08-27 · Calibration · LLMSystematically evaluates 12 open-weight LLMs across six causal graphs, five prompting strategies, and four confidence sources (verbalized, logit-based, cross-prompt agreement, cross-model agreement). Finds that while LLMs can produce plausible causal judgments, their confidence calibration varies substantially across methods — cross-model agreement provides the most reliable confidence signal.
  • 🆕 CAFE: Self-Improving Search Agents Need Co-Evolving Feedback
    HF papers · 2026-08-27 · Agent · Agent LearningOutcome-supervised search agents learn when and how to retrieve evidence, but terminal rewards cannot localize intermediate errors. CAFE couples agent and critic in a co-evolutionary loop: the critic learns to provide in-trajectory corrective feedback from outcome-confounded rollouts, while the agent learns when to request and incorporate that feedback — both improving in tandem as failure patterns shift.
  • 🆕 FARCA: Fact-Aligned Reliability-Aware Credit Assignment for Reinforcement Learning with Factual Supervision
    arXiv cs.CL · 2026-08-27 · AlignmentTackles hallucination risk from outcome-driven rewards in RLHF by introducing process-level factual supervision with reliability assessment. Decomposes the noisy factual credit assignment problem into two aspects and proposes fact-aligned credit assignment that matches verification granularity to policy update granularity, reducing the mismatch that current approaches suffer from.
  • 🆕 Joint Optimization of Tool Creation and Use for Large Language Model Agents
    HF papers · 2026-08-27 · Agent · LLMProposes SMITH, an RL framework that jointly trains a single LLM policy for both creating tools (writing API schemas) and using them. Unlike existing tool-creation systems that use a frozen LLM at inference time, SMITH ensures the schemas the model writes are schemas it can actually invoke, closing the decoupling gap between tool design and tool execution.
  • 🆕 Automata from Agent Traces: Failure and Next-Step Prediction
    arXiv cs.AI · 2026-08-27 · Agent · SafetyCollapses an entire corpus of LLM agent traces into a single compact finite-state machine that serves as a structural substrate for both failure prediction and next-step prediction. The FSM captures cross-run topology linking success and failure paths, enabling safety auditing and runtime monitoring that per-trace analysis misses.
