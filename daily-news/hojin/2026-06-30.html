  • 🆕 Support-Constrained RL Enables Real-World Policy Improvement without Real-World Experience
    arXiv cs.RO · 2026-06-30 · sim-to real RL · dexterous manipulationA real-to-sim-to-real framework that constrains RL in simulation to the support of a generative policy pretrained on real data via flow steering. Avoids sim-to-real gap exploitation while maximizing improvement. Across 8 real-world dexterous multi-fingered tasks, improves average success from 37.8% to 89.9% (vs. 59.5% for best baseline) with 36.8% fewer steps.
  • 🆕 DexCompose: Reusing Dexterous Policies for Multi-Task Manipulation with a Single Hand
    arXiv cs.RO · 2026-06-30 · dexterous manipulationA role-aware residual composition framework for reusing pretrained dexterous manipulation policies across multiple tasks with a single hand. Addresses destructive interference when adding new skills on top of existing ones, where conflicting finger demands and contact modes degrade both old and new task performance.
  • 🆕 DIM-WAM: World-Action Modeling with Diverse Historical Event Memory
    arXiv cs.RO · 2026-06-30 · WAMExtends world-action models with diverse historical event memory for long-horizon manipulation. Existing WAMs rely on short-term history and short-horizon prediction, which fails when correct execution depends on earlier observations and cross-stage task progress.
  • 🆕 Translation as a Bridging Action: Transferring Manipulation Skills from Humans to Robots
    arXiv cs.RO · 2026-06-30 · robot learningStudies learning manipulation skills from human action data for a bimanual robot with parallel grippers. Frames translation as the bridging action between fundamentally different human finger and parallel gripper contact patterns, enabling cheap and diverse human data to scale robot learning.
  • 🆕 PhysisForcing: Physics Reinforced World Simulator for Robotic Manipulation
    arXiv cs.RO · 2026-06-30Addresses physical implausibility in video-generation-based world simulators for robotic manipulation — discontinuous trajectories and inconsistent robot-object interactions. Identifies two key failure factors and applies physics reinforcement to produce dynamically consistent manipulation simulations.
  • 🆕 ReWorld: Learning Better Representations for World Action Models
    arXiv cs.CV · 2026-06-30 · WAMThe first representation learning framework specifically designed for world action models.
