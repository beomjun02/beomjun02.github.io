  • 🆕 Riemann-1.0: An Embodied World Action Model for Physical AI
    · WAM · robot foundation model · robot learningA fully causal autoregressive World Action Model that jointly models multi-view visual observations, robot states, and embodiment-specific actions within a unified sequence. Built on 200K+ hours of interaction data via progressive embodied pretraining, Riemann-1.0 achieves SOTA on RoboTwin2.0 (94.3%), LIBERO (99.0%), and RoboCasa-365 (62.6%), outperforming the previous best by 8.4%. On long-horizon real-world tasks, it reaches 85.0% success rate, exceeding the strongest open-source baseline by 15%.
  • Zero-WAM: In-Context World-Action Modeling from Human Videos for Open-Ended Task Generalization
    · WAM · robot learningBrings in-context learning to robotic manipulation by modeling world-action dynamics from human video demonstrations. Achieves zero-shot cross-task generalization—executing manipulation tasks never seen during training—by specifying new tasks purely in context without any parameter update, mirroring how LLMs handle novel text tasks via ICL.
  • 🆕 TemporalFlow-VLA: Learning Physically Grounded Execution History for Long-Horizon Robot Manipulation
    · VLA · robot learningAddresses the challenge that simply adding historical frames to VLA models does not reliably capture recent physical change. Supervises execution-aligned temporal queries with robot-surface temporal flow constructed from recorded robot states and calibrated cameras (training-only, no overhead at deployment). Achieves 97.63% average success on LIBERO including 96.60% on LIBERO Long, with clearest gains on multi-stage manipulation.
  • TacForcing: Streaming Action Generation with Execution-Time Tactile Feedback
    · VLA · dexterous manipulationIntegrates tactile feedback directly into VLA action chunk generation during execution, conditioning on evolving contact states rather than pre-execution observations alone. Avoids the complexity of separate high-frequency tactile controllers by streaming tactile signals into the action generation process, enabling more adaptive contact-rich manipulation.
  • 🆕 Rapid On-Robot Learning for Dynamic Manipulation Skills: Robot Juggling
    · robot learning · sim-to-real RL · dexterous manipulationAn online learning framework enabling a bimanual robot with multi-fingered hands and onboard vision to learn five canonical three-ball juggling patterns (cascade, tennis, half-shower, shower, box) in under 5 minutes of real-world interaction. Key insight: even an imperfect sim model is extremely useful when combined with regularized memory-based local learning and a mutually reachable safe set for continuous practice.
  • 🆕 GameWAM: A World Action Model for Video Games
    · WAMThe first World Action Model for native closed-loop gameplay and GUI control. Jointly generates future visual observations and executable keyboard-mouse trajectories through parallel generative processes with block-causal conditioning and flow matching. Uncovers Low-Frequency Action Source Imprinting (LASI), a source-sensitivity failure mode in generative control where sampled noise systematically steers camera motion.
  • 🆕 Arrive and Survive: Scaling Safe Goal-Conditioned Policy Learning from One-Bit Failure Signals
    · sim-to-real RL · robot learningIdentifies catastrophic failure bootstrapping in contrastive RL: near-failure trajectories receive disproportionately strong success supervision despite little remaining future occupancy. Proposes Safe-CRL with mass-weighted InfoNCE and log-survival-mass scoring that requires only a binary failure signal. Consistently improves both survival and goal-reaching across 12 robot navigation and locomotion tasks.
  • 🆕 Predicting Consequences and Reinforcing Navigation Policies with Latent World Models
    · robot learningA compatibility-prediction latent world model for robot navigation that evaluates action consequences in latent space rather than reconstructing observations. Enables policy learning from unlabeled video and reinforcement learning entirely within the world model, eliminating the need for action annotations or additional environment interaction. Significantly outperforms prior world model and imitation learning methods on real-world navigation datasets.
