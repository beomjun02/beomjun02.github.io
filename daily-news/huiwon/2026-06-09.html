  • 🆕 Coarse-to-Control: Action-Token Planning for Vision-Language-Action Models
    arXiv cs.RO · 2026-06-09 · VLAIntroduces a plan-execute VLA that first predicts coarse action tokens summarizing the intended trajectory, then generates fine-grained control conditioned on this plan. Both planning and execution share a unified discrete action vocabulary, enabling native long-horizon reasoning without separate planner modules.
  • 🆕 RhinoVLA Technical Report
    arXiv cs.RO · 2026-06-09 · VLAIdentifies VLM visual and context tokens as the main latency bottleneck for real-time VLA deployment. Proposes RhinoVLA, co-designed with the Huixi R1 edge SoC, using a token-efficient Qwen3-VL backbone and continuous Action Expert to reduce inference cost while maintaining manipulation performance.
  • 🆕 LARA: Latent Action Representation Alignment for Vision-Language-Action Models
    arXiv cs.RO · 2026-06-09 · VLAAddresses VLA data scarcity by jointly training a Latent Action Model with the VLA instead of the conventional separate-training pipeline. This keeps the latent action space grounded during VLA learning, enabling better use of abundant unlabeled human videos as additional supervision for robot policies.
  • 🆕 Robotic Policy Adaptation via Weight-Space Meta-Learning
    arXiv cs.RO · 2026-06-09 · VLA generalizationProposes WIZARD, a meta-learning framework that generates task-specific LoRA parameters for a frozen VLA policy given only a language instruction and a single image, eliminating the need for task-specific demonstrations or fine-tuning. Targets fast adaptation to novel tasks at deployment time.
  • 🆕 ActQuant: Sub-4-bit Action-Guided Quantization for Vision-Language-Action Models
    arXiv cs.AI · 2026-06-09 · VLAIntroduces an action-guided mixed-precision post-training quantization framework for VLAs that assigns bit-widths based on each weight matrix's contribution to action prediction accuracy. Enables sub-4-bit deployment on edge platforms where standard quantization methods cause severe performance degradation.
  • 🆕 ViVa: A Video-Generative Value Model for Robot Reinforcement Learning

  • 🆕 MotionEnhancer: Leveraging Video Diffusion for Motion-Enhanced Vision-Language Models
