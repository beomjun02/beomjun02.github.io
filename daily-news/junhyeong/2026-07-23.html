  • 🆕 Patch Policy: Efficient Embodied Control via Dense Visual Representations
    HF papers · 2026-07-23 · VLAShows that pretrained dense ViT patch features are underutilized in robot learning.   • 🆕 DWM: Separating World Effects from Actions in Latent World Models

  • 🆕 STeP: Signal Temporal Logic for Precise Specifications for Action Generation with VLAs
