Papers

  • 🆕 Attribution-Guided Pruning for Structural MoE Compression
    Structural pruning framework for Mixture-of-Experts models that reformulates prune-ratio allocation as a channel-score coverage maximization problem. On Qwen3-30B-A3B, achieves 5.27x memory reduction while preserving accuracy under 50% structured pruning combined with 4-bit quantization, consistently outperforming state-of-the-art baselines.
  • 🆕 From Sparse Features to Trustworthy Proxies: Certifying SAE-Based Interpretability
    Post-hoc generalization framework that certifies when SAE-based explanations faithfully represent a frozen LM. Derives an upper bound on base model risk using four measurable quantities: proxy risk, reconstruction gap, concept-pool mismatch, and sparse complexity. Achieves non-vacuous bounds on GPT-2 Small, Gemma-2B, and Llama-3-8B; later layers are much easier to certify due to stronger local fidelity and weaker error amplification.
  • 🆕 Sparsity Curse: Understanding RLVR Parameter Space from Model Merging
    Uncovers a sparsity curse in RLVR models: their sparse, off-principal parameter updates spread far apart in parameter space, forming near-orthogonal shortcuts that make model merging inherently fragile — the opposite of SFT models that converge to shared flat basins. Proposes SAR-Merging with Fisher Information-based sensitivity arbitration, substantially outperforming existing merging methods on RLVR models for math and coding benchmarks.
  • 🆕 JetFlow: Breaking the Scaling Ceiling of Speculative Decoding
    Causal parallel draft head that combines one-forward drafting efficiency with branch-wise causal conditioning, resolving the causality-efficiency dilemma in speculative decoding. Achieves up to 9.64x speedup on MATH-500 and 4.58x on conversational workloads on H100 GPUs across dense and MoE Qwen3 models, with vLLM integration for production serving.
  • 🆕 VISUALSKILL: Multimodal Skills for Computer-Use Agents
    Hierarchical multimodal skill library for computer-use agents organized as a central index over per-topic files consumed via an MCP tool. A Claude Code CLI agent backed by Claude Opus 4.6 reaches +15.3 point absolute lift over the no-skill baseline, with a further +8.3 point gain over text-only skills — direct evidence that retaining visual figures in skill artifacts helps agents identify UI elements and verify workflow state.
  • 🆕 The Wrong Kind of Right: Quantifying Misfired Alignment in LLMs
    Identifies misfired alignment — where safety-oriented behaviors cause LLMs to override explicit evidence in context. Introduces the VETO benchmark (2,032 contrastive pairs) and the Misfired Alignment Rate metric. All 25 tested LLMs exhibit 4.7–18.9% MAR while all human participants achieve 0.0%. Mechanistic analysis reveals late-layer suppression emerging after instruction training.
  • 🆕 SPARE: Visual Token Pruning as Subspace Reconstruction for Efficient VLMs
    Reformulates VLM token pruning as a column subset selection problem minimizing reconstruction error. Reveals a counterintuitive anti-relevance phenomenon: tokens with lower image-text relevance better preserve contextual information. Removes up to 94% of visual tokens while retaining 95% baseline performance in a fully training-free manner, with strong gains on compositional reasoning tasks.
  • 🆕 GraphPO: Graph-based Policy Optimization for Reasoning Models
    Novel RL framework representing rollouts as a directed acyclic graph with reasoning steps as edges and semantic states as nodes. Merges semantically equivalent paths into equivalence classes, enabling shared suffixes and budget reallocation from redundant to diverse exploration. Assigns efficiency advantages to incoming edges and correctness advantages to outgoing edges, consistently outperforming chain- and tree-based baselines.
  • 🆕 UniTemp: Unlocking Video Generation in Any Temporal Order
    Autoregressive video diffusion model supporting generation in arbitrary temporal directions via bidirectional distillation. Introduces blockwise anchor latents to restore missing past context during backward generation, resolving inter-block discontinuities caused by Causal 3D VAE. Enables bidirectional extension, inbetween generation, looping video, and scene transitions while maintaining competitive forward-generation quality.
