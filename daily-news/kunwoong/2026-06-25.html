  • 🆕 G³VLA: Geometric inductive bias for Vision-Language-Action Models

  • 🆕 InSight: Self-Guided Skill Acquisition via Steerable VLAs
    arXiv cs.RO · 2026-06-25 · VLAMakes VLAs steerable at the primitive-action level ("move gripper to bowl," "lift upward"), then uses this steerability for autonomous skill acquisition beyond the training data. A VLM decomposes tasks into primitives, the steerable VLA executes them, and new skills emerge without additional demonstrations.
  • 🆕 World Value Models for Robotic Manipulation
    arXiv cs.RO · 2026-06-25 · world modelsUses world model backbones instead of VLM backbones for robotic value estimation, arguing that world models inherent temporal reasoning ability makes them better suited for value prediction than VLMs trained on static observations.   • 🆕 EventVLA: Event-Driven Visual Evidence Memory for Long-Horizon VLAs
    HuggingFace Papers · 2026-06-25 · VLAAddresses the memory bottleneck in long-horizon VLA policies by introducing event-driven selective memory that retains task-relevant visual evidence rather than accumulating massive visual redundancies. Avoids the latency penalty of dual-system approaches.
  • 🆕 Autonomous Video Generation with Counterfactual Controllability for Self-Evolving World Models
    arXiv cs.CV · 2026-06-25 · world modelsChallenges the claim that video generation equals world modeling — argues current models learn partial, implicit spatiotemporal models but not fully grounded or controllable ones.
