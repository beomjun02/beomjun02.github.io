  • 🆕 PriorTR: Prior-Corrected Token Reduction for MLLMs
    arXiv · 2026-06-25 · VLM · architectureTraining-free token reduction that separates task-conditioned attention from model-induced prior in VLMs. Introduces a null token as an instruction-agnostic probe within the attention block, computing both prior and posterior in a single forward pass without duplicated propagation. Consistently improves accuracy-efficiency tradeoff, especially under aggressive token budgets.
  • 🆕 Metis: Bridging Text and Code Memory for Self-Evolving Agents

  • 🆕 AdaQ: Adaptive Quasi-Gaussian Sampling for Long Video Understanding

  • 🆕 CALIBER: Calibrating Confidence Before and After Reasoning
