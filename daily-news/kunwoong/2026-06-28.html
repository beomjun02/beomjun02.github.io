Papers

  • GeMoE: Gating Entropy for Uncertainty-aware Adaptive Routing in MoE-based Large Vision-Language Models
    Frames MoE token routing as a Minimum Description Length problem and uses gating entropy to adaptively determine how many experts each token engages. On multiple VLM backbones, retains 99.5% of static-routing performance while improving expert activation sparsity by 36.5%. 🆕
  • Nemotron-TwoTower: Diffusion Language Modeling with Pretrained Autoregressive Context
    NVIDIA decouples context encoding from denoising: a frozen AR context tower plus a trainable diffusion denoiser with bidirectional block attention. Built on Nemotron-3-Nano-30B-A3B (hybrid Mamba-Transformer MoE), trained on ~2.1T tokens — retains 98.7% of AR quality at 2.42× throughput. Code and weights released. 🆕
  • The Red Queen Gödel Machine: Co-Evolving Agents and Their Evaluators
    Evolutionary framework for recursive self-improvement under non-stationary utilities — evaluators co-evolve with agents. Uses 1.35×–1.72× fewer tokens than prior SOTA on coding; co-evolved writers achieve 1.78×–1.86× higher acceptance rates on scientific writing; co-evolved graders reach +9% ground-truth accuracy. 🆕
  • VIGIL: Mitigating Visual Laziness via Counterfactual Visual Alignment in MLLMs
    Tackles visual laziness in VLMs where models encode correct evidence but over-rely on language priors. RL post-training framework that maximizes mutual information between visual input and response via counterfactual masking. Matches SOTA with only 25% of preference data; shows emergent spatial grounding without bbox supervision. 🆕
  • Detecting and Controlling Sycophancy with Cascading Linear Features
    Isolates linearly separable sycophancy features in activation space via cascading contrastive samples. Enables deterministic scoring and robust steering that matches or outperforms LLM-as-judge baselines with lower compute and stronger interpretability guarantees. 🆕
  • Instruction Bleed: Cross-Module Interference in Prompt-Composed Agentic Systems
    Formalizes compositional behavioral leakage (CBL) — editing one prompt module silently shifts behavior of others, since transformer self-attention provides no formal boundary. Measures Cohen&#x27;s d = 0.63 content-channel effect in a deployed agent — a sub-threshold regime invisible to standard QA but compounding across thousands of decisions. 🆕
  • EpiKV: Epiphany-Aware KV Cache Eviction Without the Attention Matrix
    Scores tokens by epiphany score (change in internal representations) instead of attention weights, enabling FlashAttention-compatible cache eviction. Scales to 16× longer feasible context; at 4096-token cache reaches 72% on MATH-500 (vs. ThinKV 71%, H2O 67%) at up to 2.8× speed. 🆕
  • InfoKV: Information-Aware KV Cache Compression for Long Reasoning
    Introduces Forward Influence metric: high-uncertainty tokens have stronger influence on distant future contexts than attention-selected tokens. Combines entropy scores with attention during reasoning; consistently outperforms attention-only KV compression on Llama-3.1/3.2 and DeepSeek-R1 across long-context benchmarks. 🆕
  • Erase-then-Delta Attention: Decoupling Erase and Write Addresses in Delta-Rule Linear Attention
    Decouples where to erase from where to write in recurrent memory — a targeted erase step along a learned direction, then a delta-style corrective write. Best across dense 2.5B and MoE 25B-A2.8B families; gains persist after 80B-token long-context midtraining from 4K to 128K contexts. 🆕
  • At the Edge of Understanding: Sparse Autoencoders Trace the Limits of Transformer Generalization
    Shows OOD inputs drive LLMs to operate on more fallacious internal concepts — including subtle typos and jailbreak prompts. Uses sparse autoencoders to quantify distributional shift and enables mechanistically grounded fine-tuning to robustify LLMs. Expands OOD from input data to a model&#x27;s private computational processes. 🆕
