  • 🆕 SpecPrefetch: Parameter-Efficient Expert Prefetching for Sparse MoE Foundation Models

  • 🆕 CoSA: Accelerating Long-Context Inference via Proxy-Kernel Co-Designed Sparse Attention
    arXiv cs.CL · 2026-07-30 · kv cacheTwo-stage training-free sparse attention coupling a Kernel-Aware Proxy (moderate-budget block selection with ordered masks) and an Ordered-Skipping Kernel (tighter-budget online pruning using softmax statistics).   • 🆕 GLIDE: Guided Layerwise Hybrid Attention for Efficient LLM Inference
    arXiv cs.AI · 2026-07-30 · kv cache · architectureIntegrates sliding-window softmax attention with linear recurrent aggregation, exploiting layer-wise heterogeneity: early layers retain full softmax (high sensitivity to removal) while deeper layers use aggressive linear replacements (high redundancy). Non-uniformly compresses the softmax footprint across layers, reducing aggregate KV cache I/O while preserving expressive power where most vital.
  • 🆕 Stable FP4 Training via Transposition-Invariant Block Quantization
    arXiv cs.LG · 2026-07-30 · MoE · fundamentalIdentifies scale inconsistency from tensor transposition as the fundamental source of FP4 training instability: forward and backward passes assign different scaling factors to the same values. Proposes 2D block FP4 quantization enforcing transposition-invariant scaling, combined with truncation-free scaling and stochastic rounding. Evaluated on dense LLMs up to 7B and a 30B MoE model on 100B tokens, matching BF16 with <1.3% degradation.
  • 🆕 Raven: High-Recall Sequence Modeling with Sparse Memory Routing
    arXiv cs.LG · 2026-07-30 · architectureLinear-time model maintaining fixed memory slots with learned, input-dependent routing that decays and updates only a selected subset per step. Mitigates sliding-window attention's hard eviction and SSM-style dense interference simultaneously. Competitive with or outperforms prior linear-time baselines on recall-intensive benchmarks, extrapolating to 16x training context length, with gains composing in hybrid architectures.
