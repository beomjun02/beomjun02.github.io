  • 🆕 Metis: Memory Foundation Model
    arXiv · 2026-07-31 · architectureFirst prototype of a memory foundation model with native, gradient-free memory capabilities. Introduces a memory state within the backbone accessed via memory attention, where online memory maintenance requires only a forward pass — no gradient updates at inference. Memory procedures (store and utilize) are learned through mid-training on large-scale memory-specific data. All model weights remain frozen at inference while memory states evolve through standard forward computation.
  • 🆕 Revisiting Lossy Verification in Speculative Decoding: Mechanisms, Trade-offs, and Failure Modes
    arXiv · 2026-07-31 · architectureProvides a principled analysis of lossy verification methods for speculative decoding, classifying seemingly distinct approaches into two categories: truncation-based and collaborative verification. Identifies a fundamental pitfall: truncation-based methods can degrade below the true truncation sampling baseline. Controlling overshoot of draft probabilities relative to target probabilities is essential for quality preservation.
  • 🆕 Constitutional Midtraining: Content Presence Drives Alignment Gains
    arXiv · 2026-07-31 · trustworthyTests whether inserting values-based content into midtraining (not post-training) can produce durable alignment. Using a 394M-token corpus built from Anthropic&#x27;s Constitution at 120B scale: constitutionally midtrained models blunt blackmail propensity by -17.5pp even after benign fine-tuning. The key finding is that content presence matters more than its structure (curriculum ordering, deliberative reasoning had lesser effects).
  • 🆕 V-Steer: Steering Instruction Hierarchies at Inference Time
    arXiv · 2026-07-31 · trustworthyTraining-free method restoring privileged instruction priority by editing cached value vectors at prompt positions. Uses direct logit attribution on the first next token to identify heads where lower-priority spans dominate, then boosts privileged spans via in-place multiplicative V-tensor edits. Raises primary constraint accuracy from &lt;18% to 92% across 7B–70B models with negligible decoding overhead.

  • 🆕 GPTQ-2D: Cubic-Time Two-Sided Adaptive Rounding
    arXiv · 2026-07-31 · architectureExtends GPTQ's one-sided adaptive rounding to a two-sided version with basis matrices acting on both left and right of the residual.
