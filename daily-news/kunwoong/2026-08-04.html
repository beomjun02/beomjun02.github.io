  • 🆕 Mixture-of-Translators: Translating KV Caches Across Heterogeneous Large Language Models
    arXiv cs.CL · 2026-08-04 · kv cacheA cache translation framework (MoT) that maps context KV caches from a source LLM into a target LLM's cache space, enabling cross-architecture KV reuse without repeated prefill.   • 🆕 Hierarchical Copula-Gumbel-Top-K Routing: Two-Sided Dependence Control for Frozen MoE at Fixed Per-Token Routing Laws
    arXiv cs.LG · 2026-08-04 · MoEIntroduces a copula-based framework for controlling cross-token routing correlations in MoE models while keeping each token's routing law exactly fixed. An exchangeable Gaussian copula positively correlates within-group expert selection for coherence, while antithetic coupling across groups reduces load variance. Crucially, the base model is untouched — only a small controller over frozen features is trained, making this a novel training-free MoE routing dial.
  • 🆕 Beyond Geometric Complementarity: Coherent Overlap in Sparse Mixture-of-Experts Routing
    HF papers · 2026-08-04 · MoEChallenges the prevailing view that co-selected MoE experts must contribute distinct representation directions. Using an Expert Subspace Separation Index (ESSI), matched-route residuals, and frozen-route interventions, the study disentangles route coherence from candidate quality. Finds that coherent overlap between co-selected experts can be beneficial rather than redundant, reshaping understanding of how MoE routing works.
  • 🆕 Topology-Aware Data Movement for Disaggregated GPU Inference
    arXiv cs.LG · 2026-08-04 · kv cache · MoEAddresses the KV cache transfer bottleneck in disaggregated LLM inference where prefill and decode run on separate GPU pools (2.6 GB/request for a 70B model). Designs a topology-aware orchestrator exploiting the 72x bandwidth variation across NVLink/InfiniBand/TCP. Key mechanisms: pipelined layer-by-layer transfer hiding 60-85% of latency, NVLink domain-aware MoE expert placement co-optimizing dispatch with KV locality, and CXL 3.0 overflow at 86x lower latency than NVMe.
  • 🆕 BLADE: Boundary-Expanded and Layer-Adaptive Dynamic Exit for Efficient LLM Reasoning
    arXiv cs.CL · 2026-08-04 · test-timeA lightweight dynamic early-exit framework for reasoning LLMs that estimates whether a generated prefix is sufficient for correct answering. BLADE constructs checkpoints from sentence, self-doubt, and paragraph boundaries, learns a compact subset of informative probe layers automatically, and uses calibrated predictions for termination decisions. On Qwen3-8B, reduces generated tokens by 24.8% while preserving near-baseline accuracy across five benchmarks.
  • 🆕 Chimera: Designing and Chinchilla-Scaling Hybrid Visual Diffusion Transformers
