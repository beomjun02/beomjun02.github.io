  • 🆕 Role-Conditioned Sub-Token Routing for Efficient Vision-Language-Action Policies
    arXiv cs.LG · 2026-08-21 · VLM · kv cacheIntroduces RoleSub, which compresses VLA model KV caches by learning to selectively prune value-representation groups within retained tokens, conditioned on role and language context — complementing rather than replacing token pruning. Combined visual and language compression reduces total KV to 9.2–11.3% of original while retaining strong control performance across LIBERO benchmarks, outperforming token-only compression in 33 of 36 settings.
  • 🆕 When Safety Overrides Vision: Exploring Dynamics between Vision Influence and Safety Alignment in Vision-Language Models
    arXiv cs.CV · 2026-08-21 · VLM · trustworthyReveals that safety-aligned VLMs frequently refuse correctly answerable visual questions — not because they lose perceptual grounding, but because safety alignment overrides grounded visual expression at late decoding stages while internal visual evidence remains intact. Targeted activation interventions reliably restore grounded answering without retraining, exposing a previously underexplored failure mode where alignment suppresses useful capability.
  • 🆕 Looped Language Models Improve Compositional Tool Calling
    arXiv cs.AI · 2026-08-21 · architecture · agentEvaluates looped (recurrent-depth) language models on compositional tool-calling benchmarks (API-Bank, BFCL, NESTful) and finds recurrent computation consistently benefits multi-step, dependency-aware tool coordination. Accuracy increases with recurrent depth, and adaptive inference — allocating extra computation only when needed — achieves the best compute-performance tradeoff, suggesting looped architectures as a promising substrate for agentic systems.
  • WhiteMatter: All-to-All Cross-Layer Connections via KV Mixing
    arXiv cs.CL · 2026-08-21 · architecture · kv cacheProposes a novel architecture where every attention layer can access representations from all layers of each past token via a lightweight router that mixes L layer states into k cached KV channels. This cross-layer connectivity outperforms a vanilla Transformer with 50% more layers and achieves 50% KV-cache compression with minimal quality loss — a strong result for both architecture design and cache efficiency.
  • 🆕 FlashAttention for Scalable Vector Architectures
    arXiv cs.LG · 2026-08-21 · architecturePresents FlashAttention-V, a blocked FlashAttention implementation optimized for scalable vector CPUs (RISC-V, Arm SVE) via inter-head packing and improved register utilization. Achieves 22–42× speedup over scalar FlashAttention in prefill at 512-bit vector length, with additional 2–2.5× gains scaling to 4096-bit — and identifies a structural bottleneck in quantized linear layers that limits long-vector scalability across architectures.
  • Think Shallow, Solve Deep: Controlling Recurrent Dynamics for Reliable Test-Time Depth
    arXiv cs.LG · 2026-08-21 · test-timeShows that a measurable dynamical property (settling, marginal, or drifting regime) of recurrent-depth reasoners predicts whether additional test-time iterations help, preserve, or degrade answers. Provides a sufficient condition for depth-safety: once per-step displacement is small relative to decoder margin, answers cannot change. On algorithmic tasks, settling operators convert extra depth into higher accuracy (Sudoku: 0.19→0.34 past training horizon).
  • MoE-ViE: Mixture of Experts Vision Encoder for Efficient Image and Video Understanding

  • 🆕 StateTrace: An Object-Centric Framework for Hidden-State Spatiotemporal Reasoning in Long Videos
    arXiv cs.CV · 2026-08-21 · VLMProposes StateTrace, an object-centric framework that equips VideoLLMs with explicit hidden-state reasoning for long videos — building a reusable spatiotemporal memory of object trajectories, relations, and state transitions to reason about invisible objects during prolonged occlusion. Improves VideoLLaMA3 from 39.6 to 64.2 on HSR-Bench, a new diagnostic benchmark for hidden-state reasoning with 1,427 video-QA samples.
