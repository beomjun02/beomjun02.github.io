  • 🆕 Nexus: Depth-Adaptive KV-Cache Splicing and Retrieval-Decoupled Tool Routing for Agentic LLMsarXiv cs.AI · kv cache · agent · architectureAddresses the prefill bottleneck in agentic LLMs on the Model Context Protocol: as tool registries grow, re-encoding verbose schemas dominates TTFT. Nexus decouples routing via an INT8 semantic lookaside buffer with calibrated cross-encoder margin gate, generating arguments over a compressed 19-token signature. Routing stays ~89% accurate scaling to 250 tools — where concatenating all schemas overflows context. Achieves 1.66× faster first-argument token and ~80% context savings. Secondary KV-cache splicing lever bounded by RoPE phase drift beyond P=256. Evaluated on Qwen2.5-14B Q4_K_M, Apple silicon.
  • 🆕 Fuzzy-MoE: Interpretable Regime-Conditioned Expert Routing for Non-Stationary Time SeriesarXiv cs.LG · MoE · architecture · fundamentalReformulates time series forecasting as latent temporal state identification + interpretable expert routing via fuzzy logic. A dual-view fuzzy router infers latent states through Gaussian membership functions and computes expert activation strengths via explicit IF-THEN rules — different variables within one sequence can activate different experts. Unlike black-box MoE routing, selection is transparent and traceable with fuzzy memberships providing interpretable diagnostics. Outperforms mainstream forecasting methods across multiple benchmarks.
  • 🆕 BF1: A Causal Dyadic Sparse-Attention Retrofit for Efficient Long-Context TransformersarXiv cs.LG · architecture · kv cache · fundamentalDeterministic block-aligned dyadic sparse-attention combining local neighborhood, global first block, and logarithmically spaced historical blocks — O(n log n) interactions per layer. On RTX PRO 6000 Blackwell GPU: 10.91× per-layer prefill speedup at 32K. Retrofitting 8/28 Qwen3-0.6B layers lowers warm TTFT by 7.7–15.3% at 8–32K contexts. Under matched 1K-step, 16.4M-token adaptation, BF1 ranks first across three seeds vs. dense continued training and static-random baselines. A reproducible sparse operator for selective retrofit.
  • 🆕 CARD: Diagnosing Belief to Action Routing Failures in Vision Language ModelsarXiv cs.CV · VLM · trustworthy · fundamentalIntroduces Cross-Axis Routing Diagnostic to probe whether VLMs use internal belief representations in downstream action predictions. Steers activations along one axis while measuring another axis's response. Applied on open-weight VLMs using Relay Chain, a new cooperative grid-world benchmark, reveals a critical routing failure: models fail to incorporate belief representations into next-action prediction, leaving valuable partner information unused. Shows linear probes detect mental states the model itself ignores at inference.
  • 🆕 CertVLA: Certified Defense against Physical Visual Attacks for Vision-Language-Action ModelsarXiv cs.CV · trustworthy · agent · VLMFirst certified defense for closed-loop VLA control under bounded patch and texture attacks. Proves every certified rollout executes only action chunks consistent with attack-erased clean predictions — certificate is independent of patch content, generation method, and physical transformation. Validated in simulation and real-world settings.
  • 🆕 Self-Speculation for Faster Reasoning ModelsarXiv cs.CL · test-time · architectureTraining-free self-speculative decoding using partial chain-of-thought as drafter and full-CoT as verifier — both from the same model at different reasoning budgets.
