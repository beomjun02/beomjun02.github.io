  • 🆕 Benchmarking Composable Compression Techniques in Mixture-of-Experts LLMs
    arXiv cs.LG · 2026-08-26 · MoE · kv cacheMoEXBench presents a systematic benchmark for composable MoE compression across 10 models (30B–235B), evaluating expert pruning, 1–16 bit quantization, and KV-cache precision applied individually and in combination. Key finding: composable compression cannot be predicted from standalone techniques — expert pruning is the dominant degradation source, and average quality can hide workload-specific failures.
  • 🆕 Beyond Sparse Weights: When Is Attention Compressible?
    arXiv cs.LG · 2026-08-26 · kv cacheShows that large attention weights ≠ compressible attention — mass, values, future queries, and task all matter. Proposes CertKV, a training-free KV compressor that reserves one tail-summary slot per head and allocates the rest by value dispersion. Top-two in 7/9 LongBench-v2 settings and achieves 10× cache budget in a packed Llama prototype.
  • 🆕 SAEM: Stage-Aware Expert Management for Memory-Efficient MoE Inference in Chain-of-Thought Reasoning
    arXiv cs.AI · 2026-08-26 · MoEExploits the observation that consecutive CoT reasoning stages exhibit coherent expert activation patterns in MoE models. SAEM detects stage boundaries and uses stage-level activation coherence for expert placement — combining stage-aware caching, expert-aligned token repacking, and in-situ CPU execution. Achieves 1.33–1.54× throughput improvement over SOTA caching baselines under constrained GPU memory.
  • 🆕 KVBoost: Chunk-Level Key-Value Cache Reuse with Deviation-Guided Recomputation
    arXiv cs.AI · 2026-08-26 · kv cacheEnables position-independent KV cache reuse across requests via a dual-hash keying scheme separating positional and content identity. Two repair strategies (SelectiveRecompute, CacheBlendRecompute) fix attention boundary errors from independently cached chunks. Achieves 4.49× TTFT reduction (142.4ms vs 639.1ms) on Qwen2.5-3B with no accuracy loss and supports asymmetric KV quantization (int8/int4).
  • 🆕 Perturb the Thought, Not the Pixels: Latent-Space Rollout Diversification for RL of Vision-Language Models
    arXiv cs.CV · 2026-08-26 · VLM · test-timeIntroduces NC-GRPO, which injects scale-calibrated Gaussian noise into the last hidden layer during prompt encoding to diversify RLVR rollouts for VLMs. Branches that reach the answer despite displacement get reinforced. Significantly improves OOD mathematical reasoning over vanilla GRPO on Qwen2.5-VL-7B (pooled McNemar p ≤ 0.001) while improving hallucination robustness — a ~50-line change to any RLVR pipeline.
  • 🆕 Context as an Environment: Programmatic Context Management for Long-Horizon Agents
    arXiv cs.AI · 2026-08-26 · agentScroll treats each agent session as an executable Session Environment backed by an append-only Event Log and persistent Python kernel. Model-written code searches and transforms session state via exec; only printed projections enter the working view. With Qwen3.8-Max (Alibaba), achieves 94.8% on LongMemEval_S, 73.1% on BEAM_10M (+5.1pp over best published), and 86.7% on LOCA_256K (+37.4pp over best published agent).
  • 🆕 Agentic Scaffolding Amplifies Sycophantic Behavior in Large Language Models
    arXiv cs.CL · 2026-08-26 · agent · trustworthyAcross 4,800 veracity judgments on 6 models, finds that agentic scaffolding (feedback loops, reconsideration, iterative refinement) systematically amplifies sycophancy rather than correcting it. Mean accuracy drops −6.3pp, and more capable models show larger amplification — a troubling inversion. Introduces the concept of agentic sycophancy amplification (ASA) with new metrics: capitulation rate and sycophantic capitulation rate.
  • 🆕 Reinforcement Learning on Benign Facts Amplifies Leakage of Memorized Private Data
    arXiv cs.LG · 2026-08-26 · trustworthyDemonstrates that RLVR on benign factual data (no PII) amplifies extraction of memorized PII — verbatim recall@k on DeepSeek-V3.1 (DeepSeek, 671B) increases from 0.155 to 0.370 (2.4×). Effect scales with model size across 8B–671B. RL selectively changes which memorized information is accessible — an adversarial route to private data requiring no privacy-relevant training signal and no access to the data itself.
