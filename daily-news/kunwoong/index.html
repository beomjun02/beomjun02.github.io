  • 🆕 A-Evolve-Training: Autonomous Post-Training of a 30B Model
    arXiv cs.AI · 2026-06-24 · agentReports an autonomous system that post-trains a 30B Nemotron with no human in the loop across four rounds over multiple weeks, reaching 8th of ~4000 on the NVIDIA Nemotron-Reasoning Challenge leaderboard.   • 🆕 Sakana Fugu Technical Report

  • 🆕 Grouped Query Experts: Mixture-of-Experts on GQA Self-Attention
    arXiv cs.LG · 2026-06-24 · MoE · architectureProposes GQE, a mixture-of-experts layer on top of grouped-query attention where a router selects k query-head experts per token while all KV heads remain dense. Matches the all-active GQA baseline in downstream accuracy while activating only half the query heads per token, combining MoE efficiency gains with GQA's KV cache benefits.
  • 🆕 Tapered Language Models
    HF papers · 2026-06-24 · architectureChallenges the standard constant-width transformer stack with non-uniform parameter allocation across depth — tapering capacity so that later, less-transformative layers receive fewer parameters. A growing body of evidence suggests layers contribute non-uniformly; this work asks whether parameter capacity should reflect that asymmetry rather than defaulting to identical layers.
  • 🆕 Massive Activations Are Architecturally Robust
    arXiv cs.LG · 2026-06-24 · architecture · fundamentalTests whether massive activations (outlier hidden dimensions on the start token) are a removable artifact or a functional necessity by splitting the residual stream into a mutable scratch stream and a protected accumulator. The model rebuilds the outlier in the protected channel regardless of architecture, and stronger sparsity pressure makes it more persistent — evidence they are functional rather than incidental.
  • 🆕 Comparing Transformers and Hybrid Models at the Token Level
    arXiv cs.CL · 2026-06-24 · architectureCompares matched transformer and hybrid (attention + recurrent) models token by token. Hybrid advantage is largest on open-class content words and smallest on function words; on synthetic probes, hybrids win on pronoun-memory and entity-tracking while transformers win on bracket-matching. Suggests recurrent layers improve predictions leveraging semantic document state, while attention helps n-gram copying.
  • 🆕 Finetuning with Scientific Data Increases Hallucinations
    arXiv cs.CL · 2026-06-24 · trustworthyEvaluates 18 LLMs on SciFactCheck (2,500 prompts, 5 scientific domains) and finds that scientifically fine-tuned models exhibit degraded factual reliability across all hallucination types compared to their general-purpose bases. Fine-tuned models are internally less confident yet linguistically more assertive — fundamentally challenging current domain-specific fine-tuning for factuality.
  • 🆕 FOCA: Future-Oriented Conditioning for Data-Efficient VLA Adaptation
    arXiv cs.CV · 2026-06-24 · VLMAddresses the sharp performance degradation of VLA models under few-shot imitation learning. FOCA combines explicit future interaction embedding prediction with implicit goal-observation alignment, supporting action-free co-training with synthetic videos. Achieves 95.7% success with 20 demonstrations on LIBERO and up to 26% absolute gains on real robots.
  • DeepSeek-V4: Towards Highly Efficient Million-Token Context Intelligence
    arXiv · 2026-06-20 · MoE · architectureTwo strong MoE language models: DeepSeek-V4-Pro (1.6T params, 49B activated) and V4-Flash (284B, 13B activated), both supporting 1M-token context. Key architecture upgrades: hybrid Compressed Sparse + Heavily Compressed Attention, Manifold-Constrained Hyper-Connections, and Muon optimizer. V4-Pro requires only 27% of single-token inference FLOPs and 10% KV cache vs DeepSeek-V3.2 in 1M-token settings. Model checkpoints available.
