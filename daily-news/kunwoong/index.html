  • 🆕 CAT-Q: Cost-efficient and Accurate Ternary Quantization for LLMs
    arXiv cs.CL · 2026-06-29 · architecturePost-training ternary quantization using learnable modulation and softened ternarization that quantizes LLMs from 1.7B to 235B parameters into ternary with only 512 calibration samples. Outperforms BitNet 1.58-bit v1/v2 families trained with 100B tokens, yielding roughly a 100,000× reduction in training tokens. Scales to 235B models in 8–60 hours on 8 A100s.
  • 🆕 CascadeFormer: Depth-Tapered Transformers Motivated by Gradient Fan-in Asymmetry
    arXiv cs.LG · 2026-06-29 · architectureProposes Gradient Fan-in Asymmetry (GFA) as a structural explanation for why deeper transformer layers contribute less: gradient fan-in decays linearly with depth in Pre-LayerNorm stacks. CascadeFormer tapers width with depth to match this asymmetry, achieving comparable perplexity at same budget while reducing latency by 8.6% and increasing throughput by 9.4%. Validated up to 1.2B parameters.
  • 🆕 SharQ: Bridging Activation Sparsity and FP4 Quantization for LLM Inference
    arXiv cs.LG · 2026-06-29 · architectureTraining-free method that bridges N:M activation sparsity with FP4 quantization through online sparse-dense decomposition. Generates an input-adaptive mask to extract outlier-dominated sparse backbone, then compensates with a dense residual — both paths sharing a single FP4 weight payload. Delivers 2.2–2.4× latency reduction over FP16 on RTX 5090. No calibration or retraining needed.
  • 🆕 Staying VIGILant: Mitigating Visual Laziness via Counterfactual Visual Alignment in MLLMs
    arXiv cs.CV · 2026-06-29 · VLM · trustworthyAddresses the root cause of MLLM hallucinations: models encode correct visual evidence but over-rely on language priors during response. VIGIL introduces a geometric RL constraint that maximizes mutual information between visual input and generated response by penalizing "blind confidence." Matches full-data performance of SoTA alignment methods using only 25% of preference data and shows emergent spatial grounding without bounding box supervision.
  • 🆕 Position Rebinding Cache Reuse: Replay-Free Visual Revisiting for Interleaved Multimodal Reasoning
    arXiv cs.CV · 2026-06-29 · VLM · kv cacheIdentifies a critical failure in naive KV cache reuse for VLMs: cached visual keys carry stale positional bindings that distort attention and cause autoregressive decoding collapse. PRCR stores raw visual KV cache with original spatial coordinates, then rebinds position-compatible coordinates before injection. Improves average accuracy by 5% while reducing visual-revisiting computation by up to tens of thousands of times.
  • 🆕 ProtoKV: Streaming Video Understanding under Delayed Query with Summary-State Memory
    arXiv cs.CV · 2026-06-29 · video · kv cacheAddresses the delayed-query problem in streaming video: decisive cues may appear briefly but get evicted before the query arrives. ProtoKV aggregates far history into a fixed-capacity semantic-spatial prototype bank with residual statistics, exposed via a bounded pseudo-token interface. Improves accuracy by up to 12.5 points over token-retention baselines in the long-delay regime.
