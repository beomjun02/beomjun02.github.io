  • 🆕 HYDRA-X: Native Unified Multimodal Models with Holistic Visual Tokenizers
    arXiv cs.CV · 2026-06-14 · VLM · architectureThe first unified multimodal model that unifies image and video tokenization within a single Vision Transformer.   • 🆕 Pythagoras-Prover: Advancing Efficient Formal Proving via Augmented Lean Formalisation

  • 🆕 Arbor: Tree Search as a Cognition Layer for Autonomous Agents
    arXiv cs.AI · 2026-06-14 · agentMulti-agent framework introducing structured tree search as shared working memory for agents in large stateful action spaces. An Orchestrator delegates to Domain Specialists while a Critic agent ensures stability. Achieves up to 193% inference throughput-latency Pareto improvement over vendor-optimized baselines, where a single agent without the harness plateaus at +33% and crashes within hours.
  • 🆕 The Hidden Power of Scaling Factor in LoRA Optimization
    arXiv cs.AI · 2026-06-14 · fundamentalReveals that in LoRA, the scaling factor α is the dominant driver of effective optimization — not the learning rate. LoRA’s spectral suppression smooths the landscape, making standard hyperparameters overly conservative. The optimal α follows a square-root law with unexpectedly large coefficient, exposing insufficient scaling in existing rank-tied heuristics. LoRA-α makes LoRA compatible with standard small learning rates.
  • 🆕 Bag of Dims: Training-Free Mechanistic Interpretability via Dimension-Level Sign Patterns
    arXiv cs.LG · 2026-06-14 · architecture · fundamentalShows that the standard basis of transformer hidden states already provides a training-free, architecture-general feature basis — individual dimensions encode semantics via signs and confidence via magnitudes. A single-token cache discovers 175 semantic categories with zero training across Qwen 3.5-4B, Gemma 3-4B, and Mistral 7B. Fully unsupervised discovery scales to 1500 features at 100% yield.
