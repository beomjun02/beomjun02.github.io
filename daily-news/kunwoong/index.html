  • 🆕 COBS: Cumulant Order Block Sparse Attention
    arXiv cs.LG · 2026-07-14 · kv cache · architectureProposes a second-order cumulant statistic per KV block to improve block selection in sparse attention. Built on DeepSeek's NSA, COBS raises RULER 32K mean score from 0.30 to 0.82 (closing ~86% of the dense gap) while using only 1.21x the KV cache read traffic of the NSA baseline and 15x less than dense.
  • 🆕 KV-PRM: Efficient Process Reward Modeling via KV-Cache Transfer
    arXiv cs.AI · 2026-07-14 · kv cacheIntroduces a process reward model that directly reads the KV cache produced during generation instead of re-encoding text. Reduces scoring cost from O(L²) to O(L), achieving up to 5,000x fewer scoring FLOPs, 37x lower latency, and 34x less memory per sequence. Matches or outperforms text-PRMs on MATH, GSM8K, and AIME under beam search, MCTS, and weighted voting.
  • 🆕 Mach-Mind-4-Flash Technical Report

Pipeline includes Multi-Teacher On-Policy Distillation (MOPD) fusing RL experts across Reasoning, General, and Agent tracks, plus Hybrid Median-length Policy Optimization (HMPO) compressing reasoning chains by 19–46%. Scores 92.70 on AIME&#x27;26, 82.82 on IFBench.
  • 🆕 Director: Accelerating Distributed MoE Serving via Online Proactive Expert Placement
    arXiv cs.LG · 2026-07-14 · MoEPrediction-driven online expert placement system for MoE serving. Uses a lightweight cascaded predictor for expert activation patterns and a relaxation-based optimizer achieving (1+ε) approximation.   • 🆕 Self-Guided Test-Time Training for Long-Context LLMs
    arXiv cs.CL · 2026-07-14 · test-timeProposes S-TTT: the model first identifies evidence spans in a long context, then applies language-modeling training only to those selected spans. Random-span TTT hurts performance, but oracle-span TTT substantially helps — S-TTT bridges this gap. Achieves up to 15% relative improvement on LongBench-v2 and LongBench-Pro for Qwen3-4B and Llama-3.1-8B.
  • 🆕 MOSAIC: Adaptive Inter-layer Composition for Efficient Heterogeneous VLMs
    arXiv cs.CV · 2026-07-14 · VLM · architectureHardware-aware search that transforms homogeneous VLMs into optimized heterogeneous architectures mixing linear, sparse, and low-rank attention. Derived from Qwen3-VL-4B-Instruct using dual-teacher distillation (including a 235B oracle), MOSAIC-4B matches baseline performance with &lt;2% training cost and achieves 1.76x prefilling / 2.54x decoding speedups.
  • 🆕 Learning from Hindsight: RL Post-Training of VLAs
    arXiv cs.LG · 2026-07-14 · agentBrings hindsight relabeling to RL post-training of VLAs: a VLM scores failed rollouts against the tasks they actually achieved, and the policy trains on relabeled + original rollouts jointly. Achieves 5x sample efficiency improvement on out-of-distribution LIBERO-PRO tasks. Validated on physical Franka robot.
  • 🆕 Multimodal Reward Hacking in Reinforcement Learning
    arXiv cs.AI · 2026-07-14 · trustworthyStudies reward hacking in MLLM RL across safety VQA, chart VQA, and stress tests (2B–32B scale, GRPO/RLOO/DAPO).
