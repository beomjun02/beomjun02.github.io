  • 🆕 StateAct: Program State, before Pixels, for Long-Horizon Computer-Use Agents
    arXiv · 2026-07-29 · GUI agentA code-first, multi-agent harness that gives computer-use agents direct access to program state (files, DOM, application backends) instead of forcing them to reason from screenshots alone. Different program states can produce identical pixels, so StateAct's main agent works with structured state while a secondary agent handles visual grounding, enabling more reliable long-horizon GUI automation.
  • 🆕 SF-AMS: Strategic Forgetting for Agent Memory Systems in LLM Agents
    arXiv · 2026-07-29 · agent memoryProposes a utility-driven survival mechanism that models the long-term importance of memory units for LLM agents, replacing static retrieval and heuristic decay. Updates importance from usage, redundancy, and temporal signals to build a hierarchical memory structure. Achieves +9.65 F1 on multi-hop reasoning under Qwen2.5-7B and +6.91 F1 on temporal reasoning under GPT-4o-mini over strong baselines including LightMem and A-Mem.
  • 🆕 CORVUS: Context Optimization and Reduction for LLM Coding Agents
    arXiv · 2026-07-29 · LLM agentsAddresses a fundamental issue in coding agents: the append-only trajectory architecture captures file snapshots that become stale as code changes, causing reasoning errors and bloated contexts. CORVUS decouples file-read actions from their observations by maintaining a synchronized file registry, achieving 9–50% reduction in input tokens and up to 37% fewer reasoning cycles while maintaining pass rates on SWE-Bench.
  • 🆕 Not All LLM Reasoning is Visible in the Chain-of-Thought
    arXiv · 2026-07-29 · LLM reasoningDemonstrates that frontier models perform consequential computation with no interpretable trace in output tokens. Across 13 models and 3 tasks, models benefit from semantically irrelevant filler tokens with accuracy improvements up to 13 percentage points. Claude Opus 4.5 can even satisfy a hidden modular arithmetic constraint via filler tokens without sacrificing primary task accuracy — invisible reasoning serving objectives entirely invisible to CoT monitoring.
  • 🆕 The Physics of Multi-Turn Long-Horizon Planning: From Pre-training to Post-training
    arXiv · 2026-07-29 · agentic workflowsIntroduces a unified controlled environment to study how LLM agents acquire long-horizon planning ability across pre-training, SFT, and RL. Shows that planning ability emerges in pre-training from structured data, can be shaped via single- and multi-teacher on-policy agentic distillation during post-training, and transfers to new domains — providing a physics-like understanding of how multi-turn planning develops.
