  • 🆕 Nemotron-TwoTower: Diffusion Language Modeling with Pretrained Autoregressive Context
    NVIDIA · 2026-06-27 · LLMA block-wise autoregressive diffusion model that decouples context representation and denoising into two towers: a frozen AR context tower and a trainable diffusion denoiser with bidirectional block attention. Built on the open-weight Nemotron-3-Nano-30B-A3B MoE model and trained on ~2.1T tokens, it retains strong language understanding while enabling parallel generation.
  • 🆕 OPID: On-Policy Skill Distillation for Agentic Reinforcement Learning
    arXiv cs.CL · 2026-06-27 · on policy rlExtracts skill supervision directly from completed on-policy trajectories rather than external skill memories. Represents trajectory hindsight as hierarchical skills at episode and step levels, providing dense token-level guidance to supplement sparse outcome-based RL rewards for language agents. Avoids the mismatch between retrieved privileged context and the policy's current state distribution.
  • 🆕 The Verification Horizon: No Silver Bullet for Coding Agent Rewards
    arXiv cs.AI · 2026-06-27 · LLMArgues that as foundation models grow stronger at generating candidate solutions, reliably verifying them has become the harder problem for coding agents. Every verifier is only a proxy for human intent, subject to reward hacking and signal saturation during RL training. Formalizes this as "the verification horizon" and proposes a framework for characterizing verifier limitations.
  • 🆕 Why Multi-Step Tool-Use Reinforcement Learning Collapses and How Supervisory Signals Fix It
    HF papers · 2026-06-26 · on policy rlIdentifies that multi-step tool-use RL failures stem from unexpected probability spikes in control tokens that disrupt structured execution, while underlying capabilities remain intact. Characterizes agentic RL failure as a structural collapse problem and shows that interleaving SFT with RL, along with process reflection supervision, substantially improves training stability.
  • 🆕 SKILL-DISCO: Distilling and Compiling Agent Traces into Reusable Procedural Skills
    arXiv cs.AI · 2026-06-27 · LLMStudies procedural skill extraction from LLM agent traces in FSM-defined scenarios. Formulates skills as reusable parameterized control-flow subgraphs, then introduces a distillation-and-compilation framework that converts successful traces into callable, executable, and verifiable procedural skills that reduce redundant reasoning across similar task instances.
  • 🆕 Instruction Bleed: Cross-Module Interference in Prompt-Composed Agentic Systems
    arXiv cs.AI · 2026-06-27 · LLMFormalizes compositional behavioral leakage (CBL) — the phenomenon where editing one prompt module in an agentic system silently shifts the behavior of others sharing the same context window. Probes CBL on a deployed Claude Sonnet 4.6 agent across volume, content, and form channels, finding that only content perturbations produce detectable paired effects (Cohen's d = 0.63).
  • 🆕 Memory Depth, Not Memory Access: Selective Parametric Consolidation for Long-Running Language Agents
    arXiv cs.AI · 2026-06-27 · LLMArgues that retrieval-based memory alone is insufficient for long-running agents — durable goal-conditioned tendencies must be encoded parametrically. Introduces EVAF, a surprise- and valence-gated LoRA consolidation mechanism that outperforms retrieval on goal persistence and post-unload recovery (0.812–0.904) with only 2–3 parametric writes per 200 events.
