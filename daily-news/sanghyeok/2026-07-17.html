  • 🆕 GFlowRL: Scaling Distribution-Matching RL to Large Language Models
    arXiv cs.CL · 2026-07-17 · LLMStreamlined GFlowNet-style RL algorithm that replaces the learned partition function with an in-batch Monte Carlo estimate, scaling stably to 235B-parameter MoE models. Reaches Codeforces rating 2048 at 14B scale (within 25 Elo of o3-mini) and achieves the highest attack success rate on adversarial red-teaming benchmarks, where prior GFlowNet methods diverge.
  • 🆕 SPyCE: Skill-Policy Co-evolution for Multimodal Agents
    arXiv cs.CL · 2026-07-17 · LLMFramework that distills multimodal reasoning trajectories into a hierarchical skill library (execution skills + workflow skills) and co-evolves it with the RL policy during training. The closed loop — improved policies yield better skills, better skills improve policy rollouts — consistently outperforms both RL-based and memory-based baselines across eight benchmarks.
  • 🆕 MemCon: Memory as a Controlled Process — Learned Adaptive Memory Management for LLM Agents
    arXiv cs.CL · 2026-07-17 · LLMModels memory operations (retrieve, inject, consolidate, forget) as an MDP and learns an online policy via a lightweight tabular contextual bandit with UCB exploration. Backend-agnostic, converges within tens of tasks, and outperforms memory baselines by up to 15.2 points in success while reducing token consumption by 5–20% across 6 benchmarks, 3 agent frameworks, and 3 LLM backbones.
  • 🆕 Self-Evolving Agent Harnesses via Gated Semantic Quality-Diversity
    arXiv cs.CL · 2026-07-17 · LLMSelf-evolving framework where the LLM diagnoses failures and proposes harness patches, while deterministic code handles sampling, measurement, and significance testing. A gated categorical quality-diversity archive keys patches on (WHERE × WHY) pathology rather than tasks, providing anti-overfitting bias. Credited gains of +9 to +15.5pp retain 86–147% on sealed tests, and the winning patch tracks model pathology, not size.
  • 🆕 Self-Improvements in Modern Agentic Systems: A Survey
    arXiv cs.AI · 2026-07-17 · LLMComprehensive survey framing modern self-improving agents as adaptive systems that convert experience into accumulated capability gains. Represents an agent as a foundation model coupled with an operational scaffold (prompts, memory, tools, control logic) and formalizes self-improvement as a self-induced update operator across model parameters or scaffold components.
  • 🆕 Demystifying On-Policy Distillation: Roles, Pathologies, and Regulations
    arXiv cs.CL · 2026-07-17 · LLMSystematic study clarifying that OPD acts as an exploration catalyst — steering the student toward correct reasoning paths via dense token-level guidance without expanding the capability ceiling. Identifies two pathologies (Student-Teacher Mismatch and Length Exploitation) and shows that lightweight signal regulations (advantage clipping, log-scale compression) stably surpass OPD variants and RLVR baselines.
