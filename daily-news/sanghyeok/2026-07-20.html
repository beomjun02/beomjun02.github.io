  • 🆕 Step-Level Preference Learning for Generative Agents in Social Simulations
    arXiv cs.AI · 2026-07-20 · LLMIntroduces an interactive simulation interface that collects 57K step-level human preference annotations over agent decision trajectories. Training open-weight LLMs with supervised fine-tuning and DPO on this data consistently improves simulation fidelity and coordination, demonstrating that fine-grained human supervision at the step level is an effective signal for improving both local decision quality and long-horizon agent behavior.
  • 🆕 Reward-Free Evolving Agents via Pairwise Validator
    arXiv cs.AI · 2026-07-20 · LLMReplaces the per-step scalar reward in agent self-evolving loops with a frozen LLM pairwise validator that returns a binary better/worse verdict. This eliminates the need for domain expertise and labeled examples to design reward functions. Integrated into three self-evolving engines (GEPA, ADRS, ShinkaEvolve), the pairwise gate matches or exceeds the full-reward baseline on the majority of settings across prompt and code substrates.
  • 🆕 GRASP: GRanularity-Aware Search Policy for Agentic RAG
    HF papers · 2026-07-14 · LLMRL framework that trains an agentic RAG system to decide when to retrieve, whether to use lexical or semantic matching, and how to control context granularity to prevent irrelevant tokens from interfering with agent reasoning. Uses reinforcement learning to jointly optimize search strategy decisions rather than relying on fixed retrieval pipelines.
  • 🆕 AI Agents Do Not Fail Alone: The Context Fails First
    arXiv cs.AI · 2026-07-20 · LLMValidates context-engineering quality as an independent leading indicator of agent reliability. Implements ProofAgent-Harness with multi-juror consensus scoring across seven criteria (role clarity, guardrail coverage, instruction consistency, tool schema quality, grounding sufficiency, injection hardening, token efficiency). Holding frontier LLM agents fixed and varying only context, shows that context-quality criteria consistently predict behavioral outcomes.
  • 🆕 AdaTurn: Budget-Aware Test-Time Scaling for Active Visual Perception Agents
    arXiv cs.CV · 2026-07-20 · Gui agentAddresses "catastrophic truncation" where visual agents trained without budget awareness get cut off before producing an answer under tight turn limits. Introduces Forced-Answer DAPO that teaches models to synthesize partial evidence when further tool use is no longer possible. Raises VisualProbe-Medium from 36.7% to 47.6% at four turns while preserving scaling at larger budgets.
  • 🆕 Answer-Conditioned Chains of Thought Degrade Verifiable-Reasoning Distillation
    arXiv cs.CL · 2026-07-20 · LLMShows that showing the gold answer to a chain-of-thought generator during distillation data creation causes it to rationalize backward rather than derive forward — a damage that correctness filtering cannot catch. Training on answer-conditioned chains lowers verifiable-reasoning accuracy by up to 27 points on hard competition problems. The harm is a property of the data, not the generator, and transfers across teacher families.
  • 🆕 Eta Given Delta: Defining LLM Tool Efficiency With Marginal Tool Utility
    arXiv cs.CL · 2026-07-20 · LLMIntroduces "tool efficiency" as a direct quantitative metric for evaluating the rate of useful tool calls in an LLM agent trajectory, alongside "marginal tool utility" that indicates whether each tool call is useful or can be safely removed. Provides a post-hoc trajectory analysis framework complementing accuracy-based evaluation for agent harness engineering and lean tool suite design.
  • 🆕 SearchOS-V1: Towards Robust Open-Domain Information-Seeking Agent Collaboration
    HF papers · 2026-07-20 · LLMMulti-agent search system that addresses the problem of agents getting trapped in repetitive loops when search attempts fail to yield useful evidence.   • 🆕 Rethinking the Evaluation of Harness Evolution for Agents

  • 🆕 CIPHER: A Decoupled Exploration-Selection Framework for Test-Time Scaling of Data Science Agents
