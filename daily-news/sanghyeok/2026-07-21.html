  • 🆕 SeerGuard: A Safety Framework for Mobile GUI Agents via World Model Prediction
    arXiv cs.AI · 2026-07-21 · Gui agent · Gui world modelConsequence-aware safety framework for mobile GUI agents that uses a unified safety-augmented world model (SAWM) to predict next-state outcomes and assess action risk before execution. On Qwen3-VL-8B-Instruct, SeerGuard raises the safety-utility score from 0.191 to 0.596 and cuts the risk-cost score from 0.347 to 0.130, demonstrating effective pre-execution screening across diverse GUI agents.
  • 🆕 Process Reward Informed Tree Rollout for Effective Multi-Turn RL
    arXiv cs.CL · 2026-07-21 · LLMQuality-aware rollout framework (PATR) that replaces uniform trajectory sampling in agent RL with process-scorer-guided tree branching — selectively expanding from promising intermediate states while pruning degenerate paths. Improves SWE-Bench by +5.0 points and FrozenLake by +9.3 points, highlighting process-guided tree rollouts as an effective strategy for scalable multi-turn RL.
  • 🆕 ToolVerse: Unlocking Massive Environments and Long-Horizon Tasks for Agentic Reinforcement Learning
    arXiv cs.AI · 2026-07-21 · LLMComprehensive agentic RL framework that automatically builds training environments from nearly 400 real-world MCPs containing ~4,500 tools. Introduces a Turn-Aware Relative Advantage algorithm to address credit assignment in long-horizon tasks, significantly strengthening LLM capabilities in tool-integrated reasoning across multiple agentic benchmarks.
  • 🆕 DSWorld: A Data Science World Model for Efficient Autonomous Agents
    arXiv cs.AI · 2026-07-21Proposes a world model for data science agents that predicts environment state transitions conditioned on workflow states and candidate operations, avoiding costly trial-and-error execution. Accelerates RL-based agent training by ~14x and search-based inference by ~3-6x while maintaining competitive performance.
  • 🆕 Loop the Loopies!
    arXiv cs.CL · 2026-07-21 · LLMLoopie is the most powerful looped Transformer to date — a 20B-parameter MoE model (2B active) that substantially outperforms vanilla Transformer baselines trained with the same compute budget. Achieves gold-medal performance at the 2025 IMO and IPhO without tools, demonstrating that weight-tied looping can match parameter-scaling when done right.
  • 🆕 Understanding Reasoning from Pretraining to Post-Training
    arXiv cs.AI · 2026-07-21 · LLMUses chess as a controlled testbed to study the pretraining-to-RL pipeline end-to-end. Finds that post-RL performance is well-predicted from pretraining loss, and RL improvement rate scales approximately linearly with pretraining tokens. On hard puzzles, RL surfaces correct moves nearly absent under SFT — not just sharpening the SFT policy. The pattern transfers to math-domain text at 1B scale.
  • 🆕 Recursive Harness Self-Improvement
    arXiv cs.LG · 2026-07-21 · LLMIntroduces RHI, which iteratively refines an agent's prompt-level harness specification using pairwise feedback over its own revision history. A few iterations suffice to raise low-reasoning-effort agents above maximum-reasoning-effort settings while reducing inference cost by up to 60% — gains arising from improved inter-agent information flow rather than longer reasoning traces.
  • 🆕 Xiaomi-Robotics-1: Scaling VLA Models with over 100K Hours of Real-World Trajectories
    arXiv cs.RO · 2026-07-21Foundational VLA model pretrained on 100K+ hours of real-world manipulation trajectories with a scalable auto-labeling pipeline that annotates clips with natural-language scene-state transitions. Establishes new SOTA on RoboCasa365 (57.6% vs. prior 46.6%) and RoboDojo (20.07 vs. prior 13.07), with code and checkpoints to be released.
  • 🆕 Verbalizable Representations Form a Global Workspace in Language Models
    arXiv cs.CL · 2026-07-21 · LLMIdentifies a privileged set of representations (J-space) in LLMs that exhibit functional properties of a global workspace: reportable, deliberately summoned, used for silent reasoning, and broadly broadcast. Reveals strategic deliberation and evaluation awareness in alignment audits that never appear in model outputs. Introduces counterfactual reflection training that improves behavior by training only what a model would say if interrupted.
  • 🆕 On-Policy Delta Distillation
    HF papers · 2026-07-21 · LLMIntroduces a delta distillation signal for on-policy RL post-training that provides token-level supervision from a teacher model, moving beyond direct imitation of the teacher's output distribution. The delta signal captures the difference between teacher and student behaviors, offering a more targeted training signal for knowledge transfer in agentic settings.
  • 🆕 When Does Muon Help Agentic Reinforcement Learning?
    HF papers · 2026-07-21Studies the Muon optimizer for sparse-reward agentic RL through controlled comparisons with AdamW on ALFWorld using Qwen2.5-0.5B-Instruct. Applying Muon only to hidden weight matrices raises validation success from 0.290 to 0.546 (+88%), while high-rate AdamW controls retain no post-update success — suggesting Muon can substantially benefit agent RL training.
