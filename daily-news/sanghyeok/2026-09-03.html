  • 🆕 ZimaBlue: Evolving Generalizable World Action Models through Scalable Video Pre-training
    arXiv cs.CV · 2026-09-03A three-stage framework for learning world action models from 120,000+ hours of egocentric video: causal video pre-training, video-action mid-training with unified action representation, and target-robot specialization. An asynchronous Slow-Fast architecture enables 30 Hz action prediction; zero-shot real-robot success improves from 36.1% to 77.8% with full-scale pre-training.
  • 🆕 IMPACT: Attention Is the Interaction Map for Scalable Interaction-Aware World Model Training
    arXiv cs.AI · 2026-09-03Identifies a supervision-allocation mismatch in world model training: static content dominates the MSE signal while sparse dynamic-object regions critical to interaction are under-supervised. Uses cross-attention as an internal prior for action-conditioned changes to reweight denoising supervision, improving interaction fidelity without external representations.
  • 🆕 EmbodiedSkills: A Unified Framework for Orchestrating, Training, and Deploying VLA Agents
    arXiv cs.RO · 2026-09-03Treats each VLA skill decision as an execution proposal: checking prerequisites before execution and verifying outcomes afterward. The shared executable-skill interface connects high-level planning, bounded VLA execution, and post-action verification. Achieves 86.2% average success across 50 RoboTwin 2.0 tasks and 97.4% across LIBERO suites.
  • 🆕 Knowing When to Stop: Adaptive Action Chunking via Internal Cross-Attention Dynamics in VLAs
    arXiv cs.RO · 2026-09-03Observes that as VLA prediction horizon extends, action-to-observation cross-attention entropy rises toward a plateau — an internal signal that the current observation provides limited grounding for further open-loop execution. A training-free truncation mechanism dynamically selects execution horizons, improving task success over fixed-horizon baselines on pi0.5 and X-VLA.
  • 🆕 HyperWorld: Hypergraph-Structured State Serialization Improves Learned Textual World Models
    arXiv cs.AI · 2026-09-03Studies how state serialization structure affects learned textual world models. Entity-centered hyperedge serialization — grouping multiple related facts around entities — gives the clearest gains for 0.5B–1.5B models and under distribution shift, achieving the best out-of-distribution fact F1 and highest downstream planning success rate.
  • 🆕 Auditing Harness Tampering in Self-Improving Agents
