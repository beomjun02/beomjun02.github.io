  • 🆕 SLIDEFORGE: An LLM Agent for Controllable Editing of Slides as Structured Artifacts
    arXiv cs.CV · 2026-09-07 · Gui agent · LLMAn agentic framework that builds a structured DOM-like representation of slide internals (layout, style, component hierarchy) and uses it to perform controllable, editable modifications — preserving native editability rather than rasterizing content.   • 🆕 Learning to Zoom Efficiently with a Contrastive Curriculum
    arXiv cs.CV · 2026-09-07 · LLMProposes an InfoNCE-style intrinsic reward for teaching multimodal LLMs to use a zoom-in tool on high-resolution images, eliminating the need for warm-start supervised fine-tuning. A contrastive curriculum of increasingly hard negatives lets visual agents learn efficient zoom strategies from scratch.
  • 🆕 Speculative Macro Commit for Faster Tool-Using Agents
    arXiv cs.AI · 2026-09-07 · LLMIntroduces a two-tier agent architecture where a faster speculative drafter model continuously predicts and executes future action chains on an isolated environment copy while a larger authoritative model validates and commits correct prefixes — reducing wall-clock time for serial action-observation turns in tool-using LLM agents.
  • 🆕 Where Does Harness-Optimization Value Live? Localized Gains and the Budget-Splitting Trap in Self-Evolving LLM Agents
    arXiv cs.CL · 2026-09-07 · LLMDecomposes the LLM agent harness (persona, strategy, format rules, reflection/control) into four separately evolvable slots and shows nearly all optimization value is localized in the reflection/control slot. Uniform budget splitting across slots is actively harmful — concentrating budget on the high-credit slot recovers lost gains with half the resources.
  • 🆕 SimSkill: A Lifelong Learning AI Agent for Autonomous Mastery of Traffic Simulation
    arXiv cs.AI · 2026-09-07 · LLMA self-evolving LLM agent that identifies capability gaps, generates environment-grounded tasks, solves them through an action-critic loop, and compresses verified solutions into reusable skills — demonstrating how agents can transform accumulated experience into durable, reusable competence rather than solving individual requests in isolation.
  • 🆕 Small Language Models as Judges for Rubric-Based Reinforcement Learning
    HF papers · 2026-09-07 · LLMStudies whether small language models (under 7B) can replace expensive large-model or API-based judges for rubric-based RL reward computation.   • 🆕 MemoryLACE: Memory Lifecycle-Aware Consolidation and Evidence Retrieval
    arXiv cs.CL · 2026-09-07 · LLMA lightweight memory framework for long-term LLM agents that explicitly tracks the lifecycle of stored information — distinguishing repeated evidence, historical states, updates, and unresolved contradictions. Bridges the gap between simple semantic retrieval and complex graph-based approaches by making temporal relationships first-class citizens in memory management.
  • 🆕 Fresh Memory, Stale Plans: Dependency-Scoped Validation for Distributed LLM-Agent Memory
    arXiv cs.AI · 2026-09-07 · LLMIdentifies a "stale-plan execution" failure mode in distributed LLM-agent teams: agents can read the latest shared facts yet still act on plans derived from outdated state. Introduces PlanFence, a dependency-scoped validation protocol where plans cite the exact records they depend on, enabling executors to detect invalidation before acting.
  • 🆕 When Users Don't Ask: Benchmarking Context-Driven Memory Retrieval in Conversational Agents
    arXiv cs.CL · 2026-09-07 · LLMIntroduces LOCOMO-CONV, a conversational memory benchmark with four query styles (dialog, implicit, counterfactual, composed) that evaluates memory systems through in-situ conversational usage rather than QA-style probing. Reveals that current memory systems struggle most when users don't explicitly ask — the implicit and composed query styles expose significant retrieval gaps.
  • 🆕 Exploring Collaboration between a Language and a Non-Language Agent
