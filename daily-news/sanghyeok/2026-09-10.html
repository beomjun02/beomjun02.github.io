  • 🆕 SCAFFOLD: Self-Improving Web Agents via Recursive Parametric Skill Abstraction
    arXiv cs.AI · 2026-09-10 · Gui agentA self-improving framework for visual web agents that induces executable skills from successful trajectories, maintains a recursively composed skill hierarchy, compacts it via MDL criterion, and periodically distills augmented trajectories back into model weights. Improves success rate by 11.1–17.2pp over the strongest skill-augmented baseline across WebArena, VisualWebArena, and Online-Mind2Web.
  • 🆕 When and What to Teach: Budget-Aware Online Adaptation for Web Agents
    arXiv cs.AI · 2026-09-10 · Gui agentProposes a budget-aware online teaching framework for web agents that decides when to query a teacher model (via a solvability-aware gate) and what turns to retain (via score-guided selection). Reduces teacher calls by 22.6% and student training compute by 52.1% while maintaining comparable first-pass success on MiniWoB and TimeWarp.
  • 🆕 Beyond the Verdict: Evidence-Aligned Evaluation of Visual Prompt-Injection Guardrails
    arXiv cs.CV · 2026-09-10 · Gui agentIntroduces Mind2Web-Injection, a 9,954-pair benchmark with pixel-exact evidence boxes for evaluating VLM guardrails against visual prompt injection in web agents. Reveals that two models with nearly identical precision differ ninefold in evidence-aligned detection, and counterfactual tests show open-weight models ground verdicts in the cited evidence only 58.7% of the time.

  • 🆕 Procedural Graphs: Self-Evolving Execution Structures for LLM Agents
