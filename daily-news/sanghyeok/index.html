    arXiv cs.CL · 2026-06-29 · LLMProposes a two-tower architecture separating a frozen autoregressive context tower from a trainable diffusion denoiser tower with bidirectional block attention.   • 🆕 Instruction Bleed: Cross-Module Interference in Prompt-Composed Agentic Systems
    arXiv cs.AI · 2026-06-29 · LLMFormalizes "compositional behavioral leakage" (CBL) — editing one prompt module silently shifts behavior of others sharing a context window. Tested on a deployed Claude Sonnet 4.6 agent across 144 trials via a three-channel protocol, showing that transformer self-attention provides no formal boundary between concatenated modules.
