  • 🆕 Syll: Open-Source Personal Automation with Cross-Surface Execution
    arXiv cs.AI · 2026-06-10 · Gui agentAn open-source, self-hosted multimodal agent harness that unifies MCP/API tools, CLI execution, and visual GUI control in a modular runtime, enabling agents to coordinate actions across heterogeneous interfaces. Users teach procedures through direct demonstration, which Syll compiles into reusable skills; agent execution is translated back into multimodal evidence for inspection and control.
  • 🆕 SKILL.nb: Selective Formalization and Gated Execution for Durable Agent Workflows
    arXiv cs.AI · 2026-06-10 · Gui agentA framework governing reusable web automation workflows with evidence-calibrated lifecycle policies. Uses selective formalization where execution evidence decides which workflow steps become code vs. natural-language guided. Achieves 53.7% single-round success on WebArena-Verified and retains 91.7% of successful tasks across re-executions, outperforming persistent baselines by 15.5 points.
  • 🆕 VisualLeakBench: Action-Boundary Propagation Failures in Vision-Language Agents
    arXiv cs.CV · 2026-06-10 · Gui agentStudies how vision-language agents consuming screenshots, documents, and user interfaces propagate sensitive text from images into downstream tool arguments. On a 500-image benchmark spanning UI, chat, and dashboard scenes, target strings propagate in 78.8% of PII cases and 85.5% of unsafe-text cases; defensive system prompts only partially mitigate the issue.
  • 🆕 Q-VGM: Q-Guided Value-Gradient Matching for Flow-Matching VLA Policies
    arXiv cs.RO · 2026-06-10An off-policy RL method for fine-tuning flow-matching vision-language-action policies that avoids backpropagating through the multi-step denoising chain. Starting from a few-shot pi0.5 VLA, Q-VGM raises average success from 75.0% to 92.5% on LIBERO, 76.4% to 87.2% on RoboTwin 2.0, and 40.0% to 67.5% on real-robot tasks without additional expert supervision.
  • 🆕 Post-training is (Massive) Supervised Learning
    arXiv cs.CL · 2026-06-10 · LLMA position paper arguing that current LLM post-training (SFT + RL) effectively reverts to the pre-train-then-fine-tune paradigm of the BERT era, functioning as distribution fitting to predefined behaviors and benchmarks. Demonstrates that randomly initialized models fine-tuned on modern reasoning datasets yield highly non-trivial performance on competitive math and code benchmarks, suggesting the need to move beyond extensive post-training.
  • 🆕 TinyJudge: Unverifiable Constraint Alignment via Lightweight Specialist Ensembles
    arXiv cs.CL · 2026-06-10 · LLMProposes an ensemble of specialized ~0.6B language models to provide rewards for soft constraints in LLM instruction following, replacing expensive LLM-as-a-judge approaches that suffer from reward hacking and high compute overhead. Outperforms baselines by ~10% in average performance and 12% in reward precision while achieving 3x speedup in total training time.
  • 🆕 Customer-Agent: Tool-Augmented Agents and RLVR for Ultra-Long Shopping Trajectories
    arXiv cs.CL · 2026-06-10 · LLMIntroduces ShopTrajQA, a long-context evaluation benchmark with variants up to 64k tokens for shopping trajectory reasoning. Proposes a Customer Agent Framework using Reinforcement Learning with Verifiable Rewards, where the agent stores trajectories as external files and learns to autonomously retrieve and parse them via code-interpreter interactions, effectively bypassing LLM context window constraints.
  • 🆕 Contract2Tool: Learning Preconditions and Effects for Reliable Tool-Augmented LLM Agents
    arXiv cs.AI · 2026-06-10 · LLMInfers tool contracts — preconditions, effects, risk level, and cost — from metadata, schemas, documentation, and execution traces for reliable LLM agent tool use. Learned-contract filtering achieves 0.980 downstream success while reducing visible tools from 100 to 1 and average token usage from 26,172 to 2,528 relative to all-tools exposure.
