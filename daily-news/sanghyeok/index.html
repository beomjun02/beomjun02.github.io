  • 🆕 Trajectory-aware On-Policy Distillation via Near-Future Guidance
    arXiv cs.CL · 2026-06-03 · on policy rlShows that standard on-policy distillation for LLM reasoning suffers from a trajectory-sampled but token-learned disconnect — about 30 percent of high-loss tokens are surface-form mismatches, not real reasoning forks. Proposes TOPD, which uses near-future trajectory information to identify genuinely divergent states and distribute guidance, improving AIME24 from 60.0 to 63.3 percent and AIME25 from 46.7 to 53.3 percent.
  • 🆕 CAST: Non-Privileged Clipped Asymmetric Self-Teaching with Advantage Flipping for GRPO
    arXiv cs.AI · 2026-06-03 · on policy rlAn answer-free self-distillation method for GRPO-style verifiable-reward RL that shapes token-level advantages via a stop-gradient self-teacher. Applies bidirectional local advantage sign reversal so that zero-variance all-correct and all-wrong groups contribute meaningful gradient signal.
  • 🆕 Weak Critics Make Strong Learners: On-Policy Critique Distillation for Scalable Oversight
    arXiv cs.AI · 2026-06-03 · on policy rlStudies weak-critic strong oversight: a weak model provides non-misleading revision directions rather than solving the task. Progressive on-policy critique distillation filters high-quality critiques and distills critic-guided behavior into the strong model via adaptive self-teacher signals, demonstrating an effective path for scalable oversight.
  • 🆕 SelSkill: Learning Selective Skill Invocation in Agentic Tasks via Dual-Granularity Preference Learning
    arXiv cs.CL · 2026-06-03 · LLMAddresses whether a relevant skill should actually be invoked at the current decision point in LLM agent systems, since unhelpful invocations introduce irrelevant context and disrupt execution. Formulates skill-or-skip as dual-granularity preference learning, improving task success by 10.9pp on ALFWorld with Qwen3-8B and transferring zero-shot to new domains.
  • 🆕 SPADER: Step-wise Peer Advantage with Diversity-Aware Exploration Rewards for Multi-Answer QA
    arXiv cs.CL · 2026-06-03 · LLMA reinforcement learning framework for long-horizon tool use in multi-answer question answering. Introduces step-level credit assignment by aligning parallel trajectories at each decision step and a diversity-aware reward that upweights rare entity discoveries. Improves recall and F1 over prompting-based agents and outcome-supervised RL.
  • 🆕 FineVerify: Scaling Test-Time Compute with Fine-Grained Self-Verification for Agentic Search
    arXiv cs.CL · 2026-06-03 · LLMDecomposes each question into checkable sub-questions and verifies sampled agent trajectories against each, then selects the candidate with the highest aggregated score. With only 4 sampled trajectories, improves GPT-5-mini by 8.2 accuracy points; with 12 samples, enables GPT-5-mini to surpass frontier GPT-5 on BrowseComp-Plus.
  • 🆕 MemPro: Agentic Memory Systems as Evolvable Programs
    arXiv cs.CL · 2026-06-03 · LLMTreats the entire memory construction-retrieval pipeline as an evolvable program rather than adapting only the memory bank. An Evolving Agent maintains a version tree of runnable implementations, iteratively diagnoses recurring failures, and creates improved child versions through failure-mode-guided refinement. Consistently outperforms static and prompt-level evolving baselines.
  • 🆕 Latent Reward Steering: An Adaptive Inference-Time Framework for Reasoning LLMs
    arXiv cs.AI · 2026-06-03 · LLMTrains a latent reward model on reasoning traces to estimate quality of intermediate sparse-autoencoder latent states, then uses reward gradients to correct fragile states during inference. A reward-and-confidence gate restricts intervention to flagged states, implicitly promoting good cognitive behaviors without explicit behavior definitions.
  • 🆕 Capability Self-Assessment: Teaching LLMs to Know Their Limits
    arXiv cs.AI · 2026-06-03 · LLMShows that modern LLMs systematically overestimate their competence and attempt queries they cannot solve. Formulates capability self-assessment as a policy-learning problem and finds that RL teaches it effectively, significantly outperforming SFT while preserving capabilities. The learned self-assessment generalizes out of distribution and improves local-cloud decision making.
  • 🆕 Diversity Over Frequency: Rethinking Tool Use in Visual Chain-of-Thought Agents
    arXiv cs.CV · 2026-06-03Identifies a tool-use collapse phenomenon in visual reasoning agents: models progressively stop using tools while still achieving higher task accuracy. Completely eliminating tool use degrades performance, but incentivizing it yields only marginal gains due to reduced rollout diversity. Entropy regularization encouraging diverse exploration achieves the best reasoning performance despite declining tool usage.
