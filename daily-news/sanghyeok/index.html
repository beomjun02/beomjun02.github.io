  • 🆕 MIRAGE: Mobile Agents with Implicit Reasoning and Generative World Models
    arXiv cs.AI · 2026-06-05 · Gui agentLearns continuous latent reasoning from visible chain-of-thought traces for mobile agents, enabling implicit reasoning without decoding long rationales. Also incorporates a generative world model that aligns latent vectors with future screenshots. On AndroidWorld, matches explicit CoT SFT with 3–5x fewer decoded tokens and improves a comparable baseline by 10.2 points; on AndroidControl, reduces tokens by over 75%.
  • 🆕 Online Skill Learning for Web Agents via State-Grounded Dynamic Retrieval
    arXiv cs.AI · 2026-06-05 · Gui agentProposes stepwise skill reuse for web agents instead of static task-level retrieval. A sliding-window extraction, dual text-code representation, and state-grounded dynamic retrieval mechanism match skills to both the task goal and current webpage state. Achieves 37.5% success on WebArena with GPT-4.1, a 10.6% relative gain over the strongest baseline.
  • 🆕 Rethinking Continual Experience Internalization for Self-Evolving LLM Agents
    arXiv cs.CL · 2026-06-05 · on policy rl · LLMDiscovers that multi-iteration experience internalization in LLM agents suffers progressive capability collapse rather than compounding improvement. Shows principle-level experience outlasts instance-level, step-wise injection beats global, and off-policy context-distillation on high-quality teacher trajectories is far more stable than on-policy distillation — yielding a practical recipe for sustainable self-evolution.
  • 🆕 Read the Trace, Steer the Path: Trajectory-Aware RL for Diffusion Language Models
    arXiv cs.CL · 2026-06-05 · on policy rl · LLMIntroduces CAPR, a dLLM-RL algorithm that summarizes the denoising trace into a compact path state, generates cheap sibling continuations from cached trajectory states, and trains a block-level value head for local supervision. Recovers much of tree search granularity at roughly 0.6x the cost, setting new SOTA for RL-tuned diffusion LMs on Sudoku, Countdown, GSM8K, and Math500.
  • 🆕 Learning What to Learn: Stage-Specific Data Sets for SFT-then-RL in Small Language Model Reasoning
    arXiv cs.CL · 2026-06-05 · on policy rl · LLMArgues SFT should acquire not-yet-mastered reasoning skills while RL consolidates partially accessible ones. Proposes a Bridge mechanism that transforms teacher traces into more learnable supervision, and Critique Fine-Tuning that converts all-zero-reward RL failures into diagnostic training data. Consistently improves over representative SFT, distillation, and RL baselines on five reasoning benchmarks.
  • 🆕 AgentJet: A Flexible Swarm Training Framework for Agentic Reinforcement Learning

  • 🆕 Self-Evolving Deep Research via Joint Generation and Evaluation (SCORE)

  • 🆕 SePO: Self-Evolving Prompt Agent for System Prompt Optimization
    arXiv cs.CL · 2026-06-05 · LLMTreats the prompt agent's own system prompt as an optimization target alongside task agents' prompts. Two-stage pre-training + fine-tuning consistently outperforms Manual-CoT, TextGrad, and MetaSPO, improving average accuracy by 4.49 points across math, code, reasoning, and logic benchmarks.
