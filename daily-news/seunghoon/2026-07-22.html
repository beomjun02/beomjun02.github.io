  • 🆕 Foresight Residual RL for Long-Horizon Robot Manipulation with VLAs
    arXiv cs.RO · 2026-07-22 · VLAShows that standard residual RL over a frozen VLA improves individual subtasks but fails to chain them, because terminal state quality is uncontrolled. Foresight Residual RL adds an offline foresight value — the probability of downstream success conditioned on the current subtask's terminal state — achieving 85.6% on a three-phase nut-tightening assembly (vs. 54.5% for standard residual RL).
  • 🆕 Test-Time Scaling for World Action Models via Zero-Shot Geometric Evaluation
    arXiv cs.RO · 2026-07-22 · WAMProposes a training-free test-time scaling framework for WAMs: sample multiple rollouts, rank them by cross-view depth reprojection consistency of predicted futures using a frozen geometry model, and gate the extra compute with an action–future consistency check. Recovers 74.8% of the always-on gain while triggering additional sampling on only 26.2% of decision points.

  • 🆕 JoyNexus: Service-Oriented Multi-Tenant Post-Training for VLA Models

  • 🆕 HCPG-Flow: Contact-Progress Guidance for Flow-Policy Manipulation
