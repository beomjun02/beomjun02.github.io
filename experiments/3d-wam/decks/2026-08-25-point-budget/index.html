Appendix A4 · CHORD pipeline facts · data findings

LOAD
NVIDIA CHORD / video_to_data `LOAD` stage: one parquet schema per sequence — MANO both hands (48-d pose, betas, trans) + object 6D per body, 30 / 120 fps native. Human episodes for TACO · ARCTIC · OakInk2 · HOT3D · DexYCB come from the LOAD parquets; GRAB from the ManipTrans npz copy (PCA-24, flat_hand_mean=True — smplx default gives a 71 mm offset).
Sharpa
NVIDIA's released TACO curation only: 1,215 motion_v1.parquet (CC-BY-4.0) = MANO + Sharpa Wave link poses + object 6D at 30 fps, produced by the full CHORD pipeline including RL grounding. 1,148 carry MANO; 67 are the 34-column MANO-less variant (Sharpa + objects only) — their human episodes come from taco_loaded instead. No local retarget for any non-TACO dataset (the 4,739-task curation is not released).
Excluded
H2O (excluded by the owner) · HOT3D has no task field (objects only; text falls back to "object") · GRAB: contact_meshes/*.ply exist (metres); LOAD shards 0–3 running (job 132345); `wam` has no GRAB source yet (CHORD_DATASETS + grab_text) → preprocessed after those 3 edits.
Preprocess
15 Hz (30 → stride 2, 120 → stride 8), N = 2048 per entity from the deck #1 specs (FPS-prefix trim from 4096), T = 16, chunk stride 4 · ≤ 2 objects per sample chosen by motion / contact · entities invalid at frame 0 dropped from the chunk · contact map at 1 cm on the sampled points (KD-tree per frame) · ≈ 10.6 MB per episode · jobs 132104 (TACO: 2,250 human + 1,148 Sharpa, exit 0), 132105 (ARCTIC 277 · DexYCB 1,000 · HOT3D 294 · OakInk2 134, done 18:38) and 132345 (TACO-67 via a shadow chord_root, done → 2,317; then GRAB LOAD shards).
Units
metric_scale.py (job 132343, ≤ 200 episodes per dataset): hand extent median 17.4–20.3 cm, 0 % outside 10–35 cm; object longest side 12.1–24.0 cm; hand |dx|/step 0.23–2.10 cm; 16-step displacement 0.5–14.6 cm; up-axis proxy (smallest hand-centre variance) TACO y, DexYCB x, others z; table-height proxy 55–106 cm (OakInk2 0.1 → origin at the table).
Rates
every source rate divides both targets exactly; one chunk = 1.067 s @ 15 Hz, 1.6 s @ 10 Hz; 0 / 5,319 human and 0 / 1,215 Sharpa sequences shorter than a chunk at either rate. 10 Hz = later variant (re-preprocess with --target-fps 10).
Hands
present = non-zero 48-d pose in ≥ 1 frame; DexYCB sessions are single-hand (R 501 / L 499) → the absent hand contributes no rows (never a placeholder — PointWAM phantom-hand lesson). Contact-active rates per hand in scale.md §1.
