Method (1): Data structure

A sample is a labelled point set at t₀, its 16-step flow at 10 Hz, and a task string.

stride-4 chunks → ≈ 100k human (≈ 5.5k seqs) + ≈ 7k Sharpa (1,215 TACO seqs), Sharpa oversampled to ~25 % · TACO sequences yield paired human / Sharpa samples of one scene

Method (2): Architecture

Per-point stages stay shallow; the depth sits on 128 latents per entity.

PTv3 blocks + collate + flow normalisation reused from PointWorld (Apache-2.0) · T = 16 frames · 4 entities × 2048 points = 8,192 points per frame

Method (3): Training scheme

Flow matching on the flow, one auxiliary rigidity loss, ~10 hours per pilot.

Discussion & Action items

Three choices, each with a recommendation; then the dry run.

Discussion:

  1. Token design (owner)
    • Options: per-point tokens (full or PTv3-windowed) · entity latents + per-point query decoder
    • Recommendation: latents — 10× cheaper per pilot, point identity exact through the queries
  2. Auxiliary loss (owner)
    • Options: per-part rigidity · contact consistency (TACO contact labels)
    • Recommendation: rigidity — it is the property the Procrustes + IK decoder relies on
  3. Text encoder (owner)
    • Options: T5-base · CLIP text
    • Recommendation: T5-base — verb-level semantics, cross-attention in the DiT

Appendix A1 · evaluation plan

open-loop
held-out TACO chunks: flow ADE / FDE per class (hand · object) · rigidity residual per part · instruction-swap delta (same scene, swapped text → flow must change) · decoded Sharpa joint error after Procrustes + IK vs the paired Sharpa sample
zero-shot readout
non-TACO tasks (no Sharpa pairs): the object half of the prediction vs the human demo's object flow · hand rigidity / penetration of the generated Sharpa hand — the "robot-zero-shot on human-only tasks" claim, read open-loop first
closed-loop
later: CHORD's Sharpa-V2D-v0 Isaac Lab envs — regenerate per chunk from the simulator's frame-0 points; success rate vs an oracle replay ceiling
ablation table
the three discussion choices — token design (per-point vs latents) · aux loss (none · rigidity · contact consistency) · text encoder (T5-base · CLIP) — scored with the open-loop metrics above
held-out
TACO sequences with Sharpa pairs are the only place the decoded Sharpa joint error has a ground truth; every other dataset is human-only
