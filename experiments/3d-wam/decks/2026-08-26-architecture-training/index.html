Appendix A2 · evaluation plan · ablations

open-loop
held-out TACO chunks: flow ADE / FDE per class (hand · object) · rigidity residual per part · instruction-swap delta (same scene, swapped text → flow must change) · sample diversity across seeds (multimodality) · decoded Sharpa joint error after Procrustes + IK vs the paired Sharpa sample
zero-shot readout
non-TACO tasks (no Sharpa pairs): the object half of the prediction vs the human demo's object flow · hand rigidity / penetration of the generated Sharpa hand — the "robot-zero-shot on human-only tasks" claim, read open-loop first
closed-loop
later: CHORD's Sharpa-V2D-v0 Isaac Lab envs — regenerate per chunk from the simulator's frame-0 points; success rate vs an oracle replay ceiling
ablations
1 regression head on the same tokens (does the mean of modes fail?) · 2 21-kp sparse hands instead of 2048 points · 3 embodiment-only (no object rows) · 4 design B — latent set + temporal tokens · 5 contact-consistency aux · text encoder T5-base vs CLIP — all scored with the open-loop metrics
held-out
TACO sequences with Sharpa pairs are the only place the decoded Sharpa joint error has a ground truth; every other dataset is human-only

metrics from the text proposal / DESIGN.md §7 · CHORD env name from arXiv 2607.00033 · nothing measured yet — no runs
