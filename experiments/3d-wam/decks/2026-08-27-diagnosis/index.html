Overview

[TL;DR] The pilot trains cleanly but predicts no motion; the cause is located.

  • Ran: 12,000 steps (A) and 6,448 (B), no failures
  • Result: no better than a zero-flow baseline
  • Cause: a perfect denoiser that ignores conditioning
  • Fix: predict the flow, not the velocity

Discussion & Action items

Three cheap changes, then re-run; the scale-up waits.

  1. Change the target — predict the flow, not the velocity
    • the target then excludes the noise, so the scene is the only route to it
    • alternative: keep velocity, shift the noise schedule (SD3 / Wan style) and weight low-noise steps less
  2. Add the regression baseline — PointWorld-style, no noise at all
    • tells us whether the task is learnable from our data before we defend the generative choice
  3. Re-scale the auxiliaries — rigidity and contact are 1e-5 against 1e-2
    • they are numerically inert today; normalise each by its own initial value

Actions: A1 regression baseline + flow-target run (2 × 3 h, one GPU) · A2 re-measure with the fair metric and moving-chunk subsets · A3 re-run the transfer probes only after a run beats zero flow · A4 4× A100 design run deferred
