Appendix · how the new components work (step by step)

Chunk-chained rollout (full episodes):

  1. Load one validation episode; take its first valid frame as the start state
  2. Give the model: current frame's points + the 2 previous frames + the instruction
  3. The model generates the next 10 frames (1 s) of point positions
  4. Advance exactly 10 frames — the last predicted frame IS the next chunk's start
  5. Mode A (from truth): restart each chunk from the real recorded state → measures per-chunk quality anywhere in the episode
  6. Mode B (from itself): feed its own predicted frames back in as the next state → measures how errors compound (drift)
  7. Score every chunk against the real episode (direction + distance), stitch the whole prediction into one clip

Contact-region overlap:

  1. For every future frame, mark GT points that sit within 1 cm of the other entity — the true contact region
  2. Mark the same thing on the predicted points
  3. Score the overlap of the two regions (IoU, precision, recall)
  4. Also measure how far the predicted contact centre sits from the true one on the object — "does it touch the right place?"

Hand-feasibility gate (the IK front-end):

  1. Every hand point carries a part label (16 human hand parts; 33 robot-hand links) — native to our representation
  2. For each part, find the single best rotation+translation from frame 0 to each predicted frame (closed-form rigid fit)
  3. The leftover error after that fit is the residual: a real hand part is rigid, so GT residual ≈ 0
  4. Predicted residual ≈ GT residual → the predicted hand is a real articulated shape, and the fitted part poses ARE the input IK needs
  5. Large residual → the "hand" is noise; no joint angles exist that realise it — the gate fails before a robot ever moves

Why this is the closed-loop path:

  1. The rollout driver already runs the exact loop the robot will run — predict 1 s, step, re-observe
  2. The feasibility gate's fitted part poses feed IK → joint trajectories (next: validate by replaying decoded GT on the robot hand in sim)
  3. The arena is GR00T's own 24-task GR-1 tabletop benchmark, so success rates compare directly
