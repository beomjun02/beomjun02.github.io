3D-WAM · CONCEPT v0.3 · 2026-08-25 · NO RUNS YET

A language-conditioned generative model over labeled 4D point flow

Observation and action live in the same space: the scene and the embodiment are one dense labeled 3D point set, and a single generative model, conditioned on the frame-0 points and a language instruction, predicts the flow of the entire scene over the next chunk. Because embodiment points are part of the prediction, flow decodes to joint commands by per-link Procrustes and IK — generation is the action; there is no inverse-dynamics model, no retargeting mechanism, and no separate world model. Training mixes human demonstrations with Sharpa-hand episodes over partially overlapping task sets. The claim: the robot executes tasks demonstrated only by humans — cross-embodiment zero-shot — measured by simulated replay success against an oracle ceiling, with matched ablations of generation, density, and joint scene prediction.

Oracle replay ceiling (control)

Ground-truth mocap flow through the identical Procrustes+IK+Isaac pipeline before any model evaluation. Every later number is read relative to this ceiling.

planned

In-distribution replay

Sharpa on its trained tasks; on the same scene, swapping the instruction must change the generated behavior appropriately.

planned

Zero-shot transfer (headline)

Sharpa on tasks demonstrated only by humans. Robot-zero-shot: the model saw the task, the embodiment did not; unseen = held-out task×object combinations within the mocap vocabulary. Main figure: zero-shot success vs task-overlap fraction.

planned

Factorization analysis

Object-flow invariance under embodiment conditioning; tag-swap probe (Sharpa geometry, human tag) measuring geometry vs tag reliance.
