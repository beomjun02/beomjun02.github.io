3D-WAM · CONCEPT v0.4 · 2026-08-25 · NO RUNS YET

A language-conditioned generative model over labeled 4D point flow

Observation and action live in the same space: the scene and the embodiment are one dense labeled 3D point set, and a single generative model, conditioned on the frame-0 points and a language instruction, predicts the flow of the entire scene over the next chunk. Because embodiment points are part of the prediction, flow decodes to joint commands by per-link Procrustes and IK — generation is the action; there is no inverse-dynamics model, no retargeting mechanism, and no separate world model. Training mixes human demonstrations with Sharpa-hand episodes over partially overlapping task sets. The claim: the robot executes tasks demonstrated only by humans — cross-embodiment zero-shot — measured by simulated replay success against an oracle ceiling, with matched ablations of generation, density, and joint scene prediction.

EXPERIMENTS · PILOT

Three evaluations

Three of GRAB · TACO · OakInk2 · HOT3D · ARCTIC; human and Sharpa hand; 100–200M model; single node; no robot hardware. Numbered as in Phase 3 of the work list.

3.1

Unseen tasks — generalizability (headline)

Sharpa on tasks demonstrated only by humans. Robot-zero-shot: the model saw the task, the embodiment did not; unseen = held-out task×object cells within the mocap vocabulary, reserved from day one. Reference: the same measurement on Sharpa's trained tasks (in-distribution). Main figure: zero-shot success vs task-overlap fraction (0 / 25 / 50%).

3.2

Open-loop evaluation

Generated flow against held-out ground-truth flow, per class (object / hand) and per horizon step; on the same scene, swapping the instruction must change the generated flow appropriately. No simulator in the loop.

3.3

Closed-loop evaluation

openarm-sim (TBD): decoded joints executed chunk by chunk, regenerating per chunk. Control = the oracle replay ceiling — ground-truth flow through the identical Procrustes+IK+sim pipeline, measured before any model; every closed-loop number is read relative to it.

Datasets

Set up three datasets out of GRAB · TACO · OakInk2 · HOT3D · ARCTIC. Embodiments for now: human hand and Sharpa hand. Sharpa-hand episodes: check the CHORD (NVIDIA) release first; else ManipTrans on the same mocap with a Sharpa URDF (DexManipNet is Inspire, not Sharpa).

Deterministic uniform sampling of N points from the object and from the hand. Gallery of ~10 demos over Nobj ∈ {128, 256, 512, 1024} × Nhand ∈ {128, 256, 512, 1024}; the budget is selected by eye from the gallery (user decision).
