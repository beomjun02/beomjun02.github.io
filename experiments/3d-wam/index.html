3D-WAM · CONCEPT v0.4 · 2026-08-25 · NO RUNS YET

A language-conditioned generative model over labeled 4D point flow

Observation and action live in the same space: the scene and the embodiment are one dense labeled 3D point set, and a single generative model, conditioned on the frame-0 points and a language instruction, predicts the flow of the entire scene over the next chunk. Because embodiment points are part of the prediction, flow decodes to joint commands by per-link Procrustes and IK — generation is the action; there is no inverse-dynamics model, no retargeting mechanism, and no separate world model. Training mixes human demonstrations with Sharpa-hand episodes over partially overlapping task sets. The claim: the robot executes tasks demonstrated only by humans — cross-embodiment zero-shot — measured by simulated replay success against an oracle ceiling, with matched ablations of generation, density, and joint scene prediction.

running

Overnight — the model was better than we could measure

2026-08-30 · running — Ten trained arms, ten ablation arms, nine measurement-only investigations. Both long runs finished at 110 k steps fully annealed: history + duration reaches cosine 0.457 and ADE 12.89; duration alone 0.282 and 16.69, losing to a zero predictor by 23 % — history is worth more than nine times the compute, and hand cosine 0.544 was the first crossing of the 0.5 threshold. The decisive finding is a metric one: best-of-8 sampling reaches cosine 0.837 against a model-free ceiling of 0.861, so the distribution already contains near-optimal trajectories and the failure is selection, not capability. A 36-recipe inference sweep on an existing checkpoint reaches ADE 10.41, 29 % better than predicting nothing, with no training at all. A new interaction-quality suite adapted from the hand-object generation literature shows object shape improving 4.8× and contact placement 2× across arms, while objects still deform 23× beyond physics and contact IoU sits at 38.8 %. In the ablation, x1 parameterisation halves penetration and improves shape 33–36 %, while the rigidity loss made shape worse rather than better.

running

Rebuilt as a video generation model — 10 Hz data, time as a token axis, three designs

2026-08-28 · running — Five arms had failed the same way: the model behaves as an averager, emitting 12–28 % of true motion. Rebuilt to the video-generation contract. Data re-preprocessed at 10 Hz, human only, chunk stride 1, 512 points per entity (5,645 episodes, 848,622 chunks, 20.2 h). Time becomes a token axis instead of 48 channels; tokens are Hilbert-serialized patches of eight points (PTv3 construction used as Wan's patch embed — unpatchify verified exact, permutation equivariance 1.7e-06); RoPE on the frame index. The loss is stripped to plain masked MSE: no rigidity, no contact, no motion reweighting, no adaptive batch-RMS divisor, no autoregressive arm. Three parameter-matched arms at ~120 M — D1 patches with full attention, D2 one token per point-frame with PTv3 windowed attention (2.2× faster than full at equal tokens), D3 = D1 plus block-causal temporal attention (from MolmoMotion, whose autoregressive head beats its own flow matching). A fourth arm finetunes MolmoMotion itself for hand+object flow, and a fifth tests per-step normalised displacement targets. Result: no arm beats the zero-flow baseline (14.66 cm) — all of them slide along one ADE-vs-motion trade-off curve toward predicting nothing, with D3 the only arm holding its motion at 63 %. The binding problem is direction, not magnitude: cosine(pred, gt) is 0.145, perfect magnitude buys 8 % and still loses to a zero predictor while perfect direction buys 36 % and wins.

done

Multi-stream joint attention did not fix it — a falsified prediction

2026-08-28 · done — Per-entity-class MLP parameters with joint attention (MMDiT / RLDX-1 MSAT style), parameters matched at 119.94 M, three cells at 2,200 steps. Objects more than 10 cm from any hand move 0.56–2.64 cm against 0.06 cm true, and object motion overshoots ground truth. Hand motion unchanged. Separate parameters gave objects their own motion prior, not interaction reasoning.

running

Collapse defeated, direction missing — motion-weighted loss and an autoregressive head

2026-08-28 · running — Motion weighting lifts generated motion from 12 % to 73 % of ground truth (hand 17 % → 48 %), monotone in both runs, so the mean-collapse is beaten. Accuracy does not follow: no checkpoint beats both baselines. The autoregressive head is the best trade (ADE 0.078 at 50 % motion) and drifts on long sequences. Next: drift control, contact-gated object motion, a direction-only metric.

running

Why it does not work yet — the pilot predicts no motion, and why

2026-08-27 · running — 12,000 steps train cleanly, but the model does not beat a zero-flow baseline and its samples carry 8× too little motion. Oracle-velocity and foreign-target tests exclude sampler bugs, leakage, capacity and normalisation; the velocity target lets the model denoise instead of using the scene, so sampling collapses to the conditional mean. Fix: predict the flow, add a regression baseline, rescale the auxiliaries.

EXPERIMENTS · PILOT

Three evaluations

Three of GRAB · TACO · OakInk2 · HOT3D · ARCTIC; human and Sharpa hand; 100–200M model; single node; no robot hardware. Numbered as in Phase 3 of the work list.

3.1

Unseen tasks — generalizability (headline)

Sharpa on tasks demonstrated only by humans. Robot-zero-shot: the model saw the task, the embodiment did not; unseen = held-out task×object cells within the mocap vocabulary, reserved from day one. Reference: the same measurement on Sharpa's trained tasks (in-distribution). Main figure: zero-shot success vs task-overlap fraction (0 / 25 / 50%).

3.2

Open-loop evaluation

Generated flow against held-out ground-truth flow, per class (object / hand) and per horizon step; on the same scene, swapping the instruction must change the generated flow appropriately. No simulator in the loop.

3.3

Closed-loop evaluation

openarm-sim (TBD): decoded joints executed chunk by chunk, regenerating per chunk. Control = the oracle replay ceiling — ground-truth flow through the identical Procrustes+IK+sim pipeline, measured before any model; every closed-loop number is read relative to it.
