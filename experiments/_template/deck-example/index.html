Overview

  • Claim: robot-zero-shot on human-only tasks, read against an oracle replay ceiling

Method

One token per point track; a factorized DiT generates Δx over T = 16 at 10 Hz by flow matching.

  • Representation: xyz + class/instance label; embodiment points add link ID + tag
  • Conditioning: frame-0 points + instruction + embodiment tag → full scene flow; one loss
  • Decoding: per-link Procrustes + IK → joint commands; closed loop = regenerate per chunk
