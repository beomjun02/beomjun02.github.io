Method (1): Representation and model

One token per point; a DiT generates the flow over T = 16.

  • Representation: xyz + one group label per point
  • Conditioning: frame-0 points + instruction → scene flow
  • Decoding: per-link Procrustes + IK → joints

model table: /experiments/3d-wam/#method · backbone 100–200M for the pilot · CFM + classifier-free guidance

Method (2): Data — the point-budget sampler

Each template sampled once at N ∈ {128 … 4096}; human and Sharpa share the sweep.

  • Dense area sample → farthest-point sampling → spec
  • Sharpa pairs from CHORD's TACO release
  • Larger budget trims to smaller by FPS prefix
