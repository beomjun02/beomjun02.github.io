Verdict

The tactile model validated on BMW transfers to PnP (micro-F1 0.70 vs manual GT) and to Tool, and on the spray power-grip it recovers the ring and pinky it under-fires on PnP pinches — it is not pinky-blind, the grasp just has to load the finger. On the sim side, all three hands load and actuate every finger, but the "3/3 lift" success number from the first attempt is withdrawn: that scene pinned the bottle to the hand each step, so it measured a scripted carry, not a grasp. The real test — DPP rolled out in the PnP task on each hand, scored by the eval harness's own success_at_end — is running now.

04Hands in sim — integration only (success retracted)

What this section can and cannot claim.

Retraction

An earlier version of this log reported "3/3 lift" per hand with a mean Δz. That number is withdrawn. The scene called write_root_state_to_sim() every step to hold the bottle at a fixed offset from the hand through the close and lift, so the object rose because the script moved it — the metric measured its own teleport, not a grasp. It also was not the task that matters (the PnP benchmark). No success rate should be read off that scene.

What the scene does support is the narrow integration claim, which the Isaac smoke tests already showed independently: each hand config loads as a single articulation and every finger joint tracks a commanded target.

05Reads & caveats

  • ✓Contact prediction is not BMW-specific. PnP micro-F1 0.70 vs manual GT; contact lands on the correct fingers at closure across five object types.
  • ✓The model isn't pinky-blind. Pinky F1 0.15 on PnP pinches but 0.51 on the spray power grip — it fires the pinky when the grasp loads it.
  • ✓Both new hands load and actuate in Isaac. Single articulation, all 20 / 22 finger joints track targets — the hand-swap plumbing works.
  • ✗The "3/3 lift" success rate is retracted. The object was pinned to the hand each step; the metric measured a scripted carry. Redone properly as DPP × PnP (§06).
  • →Tool manual GT is the weak link, not the model. It marks 11.5 % of frames and never labels the thumb — the microwave clip shows a correct door-handle grasp scored as disagreement. Use the auto/proximity reference for Tool.
  • →PnP pinky recall is low (0.08). Under-fires the pinky in pinch grasps; precision stays high (0.80), so it is a miss-rate, not a false-alarm, issue.
  • ·Tool coverage is thin. microwave 10 eps, spray 3 eps; sweep and pour_coffee not run.

06The experiment being run now

The comparison that actually answers the dexterity question, in place of the retracted scene.

  • ·DPP rolled out in the PnP task, once per hand. Inspire / Wuji / Sharpa, same task, objects and seed, scored by the eval harness's own success_at_end — plus a rollout video per hand and a 3-up comparison.
  • ·Why it is the right test. DPP predicts a hand-agnostic 6-point action (wrist + 5 fingertips); retargeting it onto 20/22-DOF hands by IK is exactly the claim that the 6-point abstraction survives higher DOF. Baseline for calibration: canonical DPP on bottle ≈ 27 %.
  • ·What has to be extended. Per-hand fingertip keypoint sites + FK/IK against each hand's MJCF, and an action mapping for N independent finger joints instead of Inspire's 6→12 coupling.
