Usage guide · dex-pointwam

Human data, ready to consume — paths, statistics, schemas

Two consumers, two artifact families on the same episodes. 3D encoder (Mosaic3D-style): maskcap sidecars — per-point instance ids + captions + SigLIP2 targets, from EgoDex. PointWAM: flow H5s — metric 3D scene points + hand skeletons, from EgoDex and VITRA. Every number below was measured today; schemas were validated on random samples (63/63 passed).

Bottom line

PointWAM can train on the full flow corpus today — 324,167 EgoDex + ~822,640 VITRA episodes (~4.0 TB), every sampled file valid. 3D encoder data is at 274,526 / 324,167 EgoDex episodes (84.7%) and lands at ~5,000/hour on 24 GPUs; coverage completes 2026-08-29 midday. One thing to know before you train: captions come from three generations of the captioner (table in §01). Caption generations, in one line each. v0/v2: caption crop was the mask's bounding box, so a large surface could inherit a nearby object's description (fixed 08-19). v3: masked crop only, Qwen3-VL, short fragment captions. sf_gemma3_pass2_v1: SpaceFormer A.7 protocol verbatim (red-outline crop + masked cutout per view, up to 2 views), Gemma-3-12b, paragraph captions with a spatial-relation sentence. Only the last one sets the caption_style attribute; the older two have no such attribute and split by file mtime.

Empty captions. Instances past the per-episode caption budget carry "" and a zero row in global_siglip2 — always skip with if caps[gid].strip(). A load bug that left whole episodes uncaptioned was found and fixed on 08-28 (client-side VLM timeout under 42-way concurrency); the 6,661 affected episodes were deleted and are being reprocessed, and the writer now refuses to save a sidecar when more than 10% of its captions fail.

Schema (per clip group, keys named start:end)

KeyShapeMeaning
camera_0_scene_flows(11, N, 3) f32N tracked 3D points in world metres, one row per timestep — index i is the same physical point at every t (CoTracker3 correspondence). N ≈ 2.3k (VITRA 240p) to 10k (EgoDex).

camera_0_robot_valid(11,12) uint8EgoDex only — idle-hand mask; select keypoints by this, never by magnitude

03How to load

Sidecar and flow H5 share the filename and the clip keys, so the join is by name.

import h5py, json, numpy as np

ep   = "gather_roll_dice__1234"
flow = f"/virtual_lab/sjw_alinlab/beomjun/flows/flow_part3_pw/{ep}.h5"
side = f"/virtual_lab/sjw_alinlab/beomjun/maskcap_pilot/egodex_part3/{ep}.h5"

with h5py.File(flow) as f, h5py.File(side) as s:
    caps  = json.loads(s.attrs["global_captions"])      # {instance_id: caption}
    agent = json.loads(s.attrs["global_is_agent"])
    emb   = s["global_siglip2"][:]                      # (G, 1152) encoder target
    for ck in [k for k in f.keys() if ":" in k]:
        pts  = f[ck]["camera_0_scene_flows"][:]         # (11, N, 3) world metres
        hand = f[ck]["embodiment_joints"][:]            # (11, 50, 3) ARKit GT
        ids  = s[ck]["camera_0_instance_id"][:]         # (N,) uint16 -> caps / emb
        # encoder pair: pts[0][ids == g]  <->  emb[g-1]
        # action  pair: pts (scene) + hand (label), 11 steps @ ~10 Hz
  • ·Encoder training.Use ids > 0 points; target = emb[id-1]. Drop or down-weight global_is_agent instances if you want an object-only encoder. Filter on caption_style for a single-captioner subset.
  • ·Action training.Clips are 11 steps at ~10 Hz (stride 2 of the 20 Hz source). Select hand keypoints via camera_0_robot_valid; 6 of the 12 dex slots are placeholders in single-hand tasks.
  • ·Mixing EgoDex + VITRA.Same contract, different hand representation (50 ARKit vs 2×21 MANO) and resolution (1080p vs 240p). VITRA hand poses are reconstructed, so treat them as weaker labels for regression.

04Sanity check — what was verified

Random samples per directory, today. Report: maskcap_pilot/sanity_report.json · script maskcap_pilot/sanity_check.py.

  • ✓Sidecars 32/32 valid.Clip groups present, global_siglip2 present, max instance id ≤ SigLIP2 rows, embeddings non-zero for every captioned instance, 90–94% of points labeled.
  • ✓Flow H5 31/31 valid.All 7 EgoDex parts + VITRA: scene_flows, extrinsic, initial_rgb, embodiment_joints present with the expected shapes.
  • →Caption era is heterogeneous (the one real caveat).31% of the encoder corpus (63,066 episodes: part1 + 18.6k of part2) predates the 08-19 caption fix, so some large background instances there are described as a nearby object. Decide per use: filter by caption_style/mtime, down-weight, or re-caption (re-captioning that slice costs a full SAM2 re-run — no crop cache exists for it).
  • ·Coverage is partial, not almost-done.205,525 / 324,167 = 63.4%. Remaining: part4 21.8k, part5 70.7k, extra 20.1k, test 3.1k. At the measured 2,000 episodes/hour that is ~2.5 days (EgoDex complete ≈ 08-30); VITRA sidecars have not started.
  • ·Validation is sampled, not exhaustive.63 files opened out of 1.15 M; every sample passed. A full integrity sweep has not been run.
  • ·Known, by design.Caption style is mixed across parts (v3 Qwen vs A.7 Gemma-3) — the per-file attribute records which. Instances beyond the per-episode caption budget carry an empty caption and a zero embedding row; skip them by caps[id] != "".
  • ·Growing.Encoder sidecars land at ~2,000 episodes/hour (two-pass fleet). EgoDex 100% is the near-term milestone; VITRA sidecars start after it.
