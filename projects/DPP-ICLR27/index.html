DPP-ICLR27 — One Frozen Human Hand Policy, Many Robot Hands

Working notes, written as short papers · updated 2026-08-08

Central claim under construction: a manipulation policy trained only on human hand data can drive multiple dexterous robot hands through small, per-hand retargeters that are trained with no robot demonstrations and no task data — pairs are distilled from functional (object-motion-equivalent) transfer in simulation. Each workstream below is documented as a self-contained short paper; results land in the placeholder sections as runs complete.
